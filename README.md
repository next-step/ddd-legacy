# 키친포스

## 퀵 스타트

```sh
cd docker
docker compose -p kitchenpos up -d
```

## 요구 사항
### 메뉴 그룹
- [ ] 메뉴 그룹은 메뉴 포함될 수 있는 그룹을 의미한다.
- [ ] 등록되어 있는 메뉴 그룹의 목록을 확인할 수 있다.
### 메뉴
- [ ] 메뉴 등록하기 위해서는 메뉴 그룹 등록이 선행되어야 한다.
- [ ] 메뉴 등록하기 위해서는 상품 등록이 선행되어야 한다.
- [ ] 메뉴 등록시 메뉴 재고를 설정할 수 있다.
- [ ] 메뉴 등록시 포스기에서 메뉴를 확인할 수 있다.
- [ ] 메뉴 가격을 변경할 수 있다.
- [ ] 메뉴를 공개 시킬 수 있다.
- [ ] 메뉴를 비공개 시킬 수 있다.
- [ ] 등록되어 있는 메뉴 목록을 확인할 수 있다.
### 주문 테이블
- [ ] 주문 테이블 등록 시 테이블 사용 가능여부라는 상태를 갖지만, 의미없는 상태이다.
- [ ] 주문 테이블 등록 시 손님수라는 상태를 갖지만, 의미없는 상태이다.
- [ ] 주문 테이블 사용 가능 여부 상태를 변경할 수 있다.
- [ ] 주문 테이블 손님수를 변경할 수 있다.
- [ ] 등록되어 있는 주문 테이블 목록을 확인할 수 있다.
- [ ] 주문 테이블은 주문이 홀 타입일 시 유의미한 정보이다.
### 주문
- [ ] 주문을 등록하기 위해서는 주문 테이블 등록이 선행되어야 한다.
- [ ] 주문을 등록하기 위해서는 메뉴 등록이 선행되어야 한다.
- [ ] 주문은 홀, 배달이라는 타입을 갖는다.
- [ ] 주문은 수락, 서빙, 배달 시작, 배달 완료, 완료 상태를 갖는다.
- [ ] 주문 등록 시 기본적으로 수락 상태를 갖는다.
- [ ] 등록되어 있는 주문 목록을 확인할 수 있다.
### 상품
- [ ] 상품 가격을 수정할 수 있다.
- [ ] 등록되어 있는 상품 목록을 확인할 수 있다.

# 키친포스

## 퀵 스타트

```sh
cd docker
docker compose -p kitchenpos up -d
```

## 요구 사항
- 상품과 메뉴를 등록하고 주문하는 키친포스 시스템을 구현합니다.
### 상품
> 상품이란 판매될 수 있는 물건이나 음식등을 의미합니다.
> 
> 여기서는 음식이 상품이 될 수 있을 것입니다. (치킨, 피자 등등)
- [ ] 상품 등록 기능 - 상품 가격과 상품명을 입력하여 등록합니다.
  - [ ] 상품명과 가격을 필수로 입력받습니다.
  - [ ] 상품명이 없거나 비속어가 있으면 안됩니다.
  - [ ] 가격은 0원 이상이어야 하며, 없거나 0원보다 작으면 안됩니다. 
- [ ] 가격 변경 기능 - 상품의 가격을 변경할 수 있습니다.
  - [ ] 등록되어 있는 상품의 id와 변경할 상품 정보(상품명, 가격, id)를 입력받습니다.
  - [ ] 변경할 상품의 가격은 0원이상이고, 없거나 0원 미만이 되면 안됩니다.
  - [ ] 상품 id는 등록되어 있는 상품이어야 합니다.
  - [ ] 메뉴의 상품들(동일 상품일수도 있고, 다른 상품일 수도 있습니다.) 
  의 총 가격 합이 메뉴의 가격보다 크면, 유효하지 않습니다.
  - [ ] 유효하지 않은 메뉴는 화면에서 노출하지 않습니다.
-[ ] 모든 상품을 조회할 수 있습니다.

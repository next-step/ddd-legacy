# 키친포스

## 퀵 스타트

```sh
cd docker
docker compose -p kitchenpos up -d
```

## 요구 사항

### 상품

- 판매를 위한 기본 상품 정보를 나타낸다.
    - ex) 후라이드 16000원, 간장치킨 17000원
- 상품 등록
    - 상품은 이름과 가격을 필수로 가진다.
    - 상품 등록 시 이름의 유해성 여부를 검사한다.
- 가격 변경
    - 지정한 상품의 가격을 변경할 수 있다.
    - 가격이 변경되면 해당 상품을 포함한 모든 메뉴의 가격을 검증 후 메뉴를 숨김처리한다.
        - 가격 변경 후 메뉴에 포함된 상품 가격 총합이 메뉴의 가격보다 작아야 한다.
- 상품 조회
    - 등록된 모든 상품의 목록을 조회한다.

### 메뉴

- 판매를 위한 단일 항목으로 고객에게 상품을 표시되는 단위가 된다.
    - ex) 후라이드치킨(메뉴)는 후라이드(상품)을 포함한다.
- 메뉴 등록
    - 메뉴의 가격은 0원 이상이어야 한다.
    - 메뉴 그룹을 지정해야한다.
    - 등록된 상품중 1개 이상을 지정해야 한다.
    - 메뉴의 가격은 지정한 상품들의 가격 총합보다 작아야 한다.
    - 메뉴의 이름은 비속어를 포함할 수 없다.
- 가격 변경
    - 지정한 메뉴의 가격을 변경할 수 있다.
    - 가격은 0원 이상으로 변경할 수 있다.
    - 변경된 가격은 메뉴에 포함된 상품들의 총합보다 작아야 한다.
- 노출
    - 지정한 메뉴를 노출한다.
    - 메뉴의 가격이 메뉴에 포함된 상품들의 총합보다 작은 경우에만 노출처리할 수 있다.
- 숨김
    - 지정한 메뉴를 숨김처리한다.
- 메뉴 조회
    - 등록된 모든 메뉴를 조회한다.

### 메뉴 그룹

- 메뉴들을 분류하는 상위 그룹을 나타낸다.
    - ex) 후라이드치킨(메뉴), 양념치킨(메뉴)을 한마리메뉴(메뉴그룹)로 묶을 수 있다.
- 메뉴 그룹 등록
    - 메뉴 그룹은 이름을 필수로 가진다.
- 메뉴 그룹 조회
    - 등록된 모든 메뉴 그룹을 조회한다.

### 주문

- 고객의 주문을 나타낸다.
    - 주문 유형 : 배달(DELIVERY), 포장(TAKEOUT), 매장식사(EAT_IN)
    - 주문 상태 :
        - 대기(WAITING) : 주문이 등록됨
        - 수락(ACCEPTED) : 가게에서 주문을 수락함
        - 제공(SERVED) : 모든 메뉴 준비가 완료됨
        - 배달중(DELIVERING) : 고객에게 배달 중
        - 배달완료(DELIVERED) : 고객이 상품을 수령함
        - 완료(COMPLETED) : 주문이 완료됨
- 주문 생성
    - 주문 유형은 배달(DELIVERY), 포장(TAKEOUT), 매장식사(EAT_IN) 중 하나를 가져야 한다.
        - 주문 유형이 배달주문이면 배달주소를 입력해야한다.
        - 주문유형이 매장식사면 지정한 주문테이블이 사용중이어야 한다.
    - 주문 항목을 1개 이상 포함해야 한다.
    - 등록된 메뉴만 주문 항목에 포함될 수 있다.
    - 주문유형이 배달, 포장이면 주문한 메뉴의 수량은 반드시 1 이상어야 한다.
    - 전시중이 아닌 메뉴는 주문할 수 없다.
    - 주문 요청의 가격과 메뉴의 가격일치해야 한다.
    - 생성한 주문은 대기 상태가 된다.
- 수락
    - 주문 상태를 수락(ACCEPTED)으로 변경한다.
    - 대기(WAITING)중인 주문만 변경할 수 있다.
    - 배달 주문일 경우 배달요청을 보내야 한다.
- 제공
    - 주문 상태를 제공(SERVED)으로 변경한다.
    - 수락(ACCEPTED)된 주문만 변경할 수 있다.
- 배달시작
    - 주문 상태를 배달중(DELIVERING)으로 변경한다.
    - 제공(SERVED)된 주문만 변경할 수 있다.
    - 주문 유형이 배달 주문일 경우만 변경할 수 있다.
- 배달완료
    - 주문 상태를 배달완료(DELIVERED)로 변경한다.
    - 배달중(DELIVERING)인 주문만 변경할 수 있다.
- 완료
    - 주문 상태를 완료(COMPLETED)로 변경한다.
    - 주문 유형이 배달주문이면 배달완료(DELIVERED) 상태일 경우에만 변경할 수 있다.
    - 주문 유형이 포장주문, 매장식사면 제공됨(SERVED) 상태일 경우에만 변경할 수 있다.
    - 주문 유형이 매장식사일 때 주문 테이블을 정리한다.
        - 해당 주문 테이블의 주문이 모두 완료 상태여야 한다.

### 주문 테이블

- 매장에서 주문을 받기 위한 테이블을 나타낸다. 이름, 손님 수, 사용여부를 가진다.
    - 사용여부는 해당 테이블에 손님의 착석 유무를 표현한다.
- 주문 테이블 등록
    - 이름으로 주문 테이블을 생성한다.
    - 생성한 주문테이블은 손님수 0, 미사용 상태가 된다.
- 착석
    - 주문테이블을 사용중으로 변경한다.
- 정리
    - 주문 테이블의 미사용 변경하고 손님수를 0으로 설정한다.
    - 현재 주문테이블의 모든 주문이 완료상태일 때 정리할 수 있다.
- 손님수 변경
    - 손님 수를 0 이상으로 변경할 수 있다.
    - 점유상태인 주문 테이블만 변경할 수 있다.
- 주문 테이블 조회
    - 모든 주문 테이블 목록을 조회한다.

# 키친포스

## 퀵 스타트

```sh
cd docker
docker compose -p kitchenpos up -d
```

## 요구 사항

- 가게에서 상품과 메뉴를 등록하고 이를 주문하는 키친 포스 시스템을 구현합니다.

    1. 상품
        1) 상품 등록
            - 상품가격은 0원 이상이어야 한다.
            - 상품명은 외부 검증을 통해 욕설이나 외설성이 있으면 안된다.
            - 상품명은 1글자 이상이어야 한다.
            - 위의 조건이 모두 적합하다면 상품명과 상품가격에 맞는 `상품 id`를 생성하고 이 `상품정보`를 등록한다.
        2) 상품가격 변경
            - 상품가격은 0원 이상이어야 한다.
            - 상품정보는 등록된 상품정보여야 한다.
            - 가져온 상품정보의 상품가격을 변경한다.
            - 상품 id를 통해 현재 변경된 상품정보를 갖고 있는 메뉴를 전부 가져온다.
            - 상품가격들의 총합이 메뉴의 가격보다 낮으면 메뉴의 진열여부를 미진열로 변경한다.
        3) 상품 조회

    2. 메뉴 그룹
        1) 메뉴 그룹 등록
            - 메뉴그룹명은 1글자 이상이어야 한다.
            - 위 조건이 적합하다면 메뉴그룹명과 이에 맞는 `메뉴그룹 id`를 생성하고 이 `메뉴그룹정보`를 등록한다.
        2) 메뉴 그룹 조회

    3. 메뉴
        1) 메뉴 등록
            - 메뉴가격은 0원 이상이어야 한다.
            - 메뉴그룹 id를 통해 메뉴 그룹을 찾을 수 있어야 한다.
            - 메뉴 상품들은 메뉴에 존재해야만 한다.
            - 메뉴 상품의 상품 갯수와 메뉴에 등록된 상품정보의 갯수는 동일한 갯수여야한다.
            - 메뉴 상품들의 수량은 0보다 많아야 한다.
            - 메뉴 상품의 상품은 등록이 된 상품이어야 한다.
            - 메뉴 상품은 상품과 수량을 등록할 수 있다.
            - 등록하려는 메뉴가격이 메뉴에 포함된 상품 가격의 합보다 크면 안된다.
            - 메뉴명은 1글자 이상이어야 한다.
            - 위의 조건이 모두 적합하다면 메뉴명, 메뉴가격, 메뉴그룹, 진열여부, 메뉴 상품과 이에 맞는 `메뉴 id`를 생성하고 이 `메뉴정보`를 등록한다.
        2) 메뉴가격 변경
            - 메뉴가격은 0원 이상이어야 한다.
            - 메뉴정보는 등록된 메뉴정보여야 한다.
            - 메뉴 상품들의 가격 합보다 수정하려는 가격보다 크면 안된다.
            - 메뉴정보의 메뉴가격을 변경한다.
        3) 메뉴 진열
            - 메뉴정보는 등록된 메뉴정보여야 한다.
            - 메뉴 상품들의 가격 합보다 메뉴 가격이 크면 안된다.
            - 위 조건을 모두 만족하면 메뉴의 진열여부는 진열로 변경된다.
        4) 메뉴 미진열
            - 메뉴 정보는 등록된 메뉴정보여야 한다.
            - 위 조건을 만족하면 메뉴의 진열여부는 미진열로 변경된다.
        5) 메뉴 조회

    4. 주문
        1) 주문 등록
            - 주문 유형은 배달, 테이크아웃, 매장 중에 선택되어야 한다.
            - 주문 상품들은 존재해야만한다.
            - 주문 상품들은 존재하는 메뉴들이어야한다.
            - 주문 상품의 갯수와 이에 맞게 등록된 메뉴의 갯수는 동일해야 한다.
            - 주문 유형이 매장이 아니라면 주문상품의 갯수는 0보다 커야한다.
            - 주문의 메뉴는 존재해야하는 메뉴여야한다.
            - 메뉴의 가격과 주문메뉴의 가격은 같아야 한다.
            - 위의 조건을 모두 만족한다면 주문 상품들은 메뉴, 수량, 주문 상품으로 구성된다.
            - 처음 주문을 받으면 주문상태는 대기상태이다.
            - 주문 시간은 현재시간으로 한다.
            - 주문 유형이 배달일시 배달 주소는 필수적이다.
            - 주문 유형이 매장일시 매장내 가능한 주문 테이블이 존재해야 한다.
            - 위의 조건이 모두 만족한다면 이에 맞는 `주문id`를 생성하고 `주문정보`를 등록한다.
        2) 주문 수락
            - 주문 정보는 등록된 주문 정보여야한다.
            - 현재 주문상태가 대기상태여야한다.
            - 주문 유형이 배달이라면 배달원에게 주문 id, 배달주소, 주문상품들의 가격을 통해 배달 요청할 수 있다.
            - 배달 요청에 성공했다면 주문상태는 수락으로 변경된다.
        3) 서빙
            - 주문 정보는 등록된 주문 정보여야한다.
            - 현재 주문상태가 수락이면 안된다.
            - 주문 상태는 서빙됨으로 변경된다.
        4) 배달 시작
            - 주문 정보는 등록된 주문 정보여야한다.
            - 배달시작은 주문 유형이 배달일때만 가능하다.
            - 주문 상태가 서빙이면 안된다.
            - 위에 조건을 만족한다면 주문상태는 배달 중으로 변경된다.
        5) 배달 완료
            - 주문 정보는 등록된 주문 정보여야한다.
            - 주문상태가 배달 중이어야 한다.
            - 위 조건을 만족한다면 주문상태는 배달됨으로 변경된다.
        6) 주문 완료
            - 주문 정보는 등록된 주문 정보여야한다.
            - 주문 유형이 배달일 때, 주문 상태가 배달됨이 아니라면 주문이 완료되지 않았다.
            - 주문 유형이 테이크아웃이거나 매장일 때, 주문 상태가 서빙됨이 아니라면 주문이 완료되지 않았다.
            - 주문 유형이 매장일 때, 주문 테이블 상태가 전부 제공완료라면 주문 테이블의 인원을 0으로 변경하고 사용가능 상태로 변경한다.
        7) 주문 조회
       
    5. 주문 테이블
        - [ ]  사용자는 트레이너라고 부른다.

## 용어 사전

| 한글명     | 영문명           | 설명                                                                    |
|---------|---------------|-----------------------------------------------------------------------|
| 상품 id   | ProductId     | 상품명과 상품가격에 매칭되는 상품 정보의 고유 값 혹은 번호                                     |
| 상품정보    | ProductInfo   | 상품 id, 상품명, 상품가격으로 구성되어 저장하는 상품의 정보들의 집합                              |
| 메뉴그룹 id | MenuGroupId   | 메뉴그룹명에 매칭되는 메뉴그룹 정보의 고유 값 혹은 번호                                       |
| 메뉴그룹정보  | MenuGroupInfo | 메뉴그룹 id, 메뉴그룹명 구성되어 저장하는 메뉴그룹의 정보들의 집합                                |
| 메뉴 id   | MenuId        | 메뉴에 매칭되는 메뉴 정보의 고유 값 혹은 번호                                            |
| 메뉴정보    | MenuInfo      | 메뉴명, 메뉴가격, 메뉴그룹, 진열여부, 메뉴 상품, 메뉴 id로 구성되어 저장하는 메뉴의 정보들의 집합            |
| 주문 id   | OrderId       | 주문에 매칭되는 주문 정보의 고유 값 혹은 번호                                            |
| 주문정보    | OrderInfo     | 주문 유형, 주문상태, 주문시간, 주문상품들, 배달 주소, 주문 테이블, 주문 id로 구성되어 저장하는 주문의 정보들의 집합 |

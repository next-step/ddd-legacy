# 키친포스

## 퀵 스타트

```sh
cd docker
docker compose -p kitchenpos up -d
```

## 요구 사항
메뉴
- [ ] 메뉴를 등록할 수 있다.
- [ ] 전체 메뉴를 조회할 수 있다.
- [ ] 메뉴의 가격을 수정할 수 있다.
- [ ] 메뉴의 노출 여부를 변경할 수 있다.
- [ ] 메뉴 생성 시 메뉴 구성 상품과 메뉴 그룹이 존재해야 한다.
- [ ] 메뉴는 하나 이상의 메뉴 그룹을로 등록할 수 있다.
- [ ] 메뉴의 가격은 0원 이상이어야 한다.
- [ ] 메뉴의 이름은 빈 문자열이거나 null일 수 없다.

메뉴 상품
- [ ] 메뉴와 상품 간의 수량을 등록할 수 있다.
- [ ] 메뉴는 1개 이상의 상품을 포함한다.

메뉴 그룹
- [ ] 메뉴 그룹을 등록할 수 있다.
- [ ] 메뉴 그룹을 조회할 수 있다.
- [ ] 메뉴 그룹명은 빈 문자열이거나 null일 수 없다.

상품
- [ ] 상품을 등록할 수 있다.
- [ ] 전체 상품을 조회할 수 있다.
- [ ] 상품의 가격을 수정할 수 있다.
- [ ] 상품명은 빈 문자열이거나 null일 수 없다.
- [ ] 상품의 가격은 0원 이상이어야한다.

주문
- [ ] 주문을 등록할 수 있다.
- [ ] 주문의 상태를 변경시킬 수 있다.
- [ ] 주문을 조회할 수 있다.
- [ ] 주문은 하나 이상의 주문 내역에 포함된다.
- [ ] 주문 생성 시 해당하는 메뉴의 존재 및 수량을 검증한다.
- [ ] 주문은 WAITING, ACCEPTED, SERVED, DELIVERING, DELIVERED, COMPLETED 상태를 갖는다.
- [ ] 주문은 상태 및 타입에 따라 주소값이 null일 수 있다.
- [ ] 주문은 DELIVERY, TAKEOUT, EAT_IN 타입을 갖는다.

주문 테이블
- [ ] 주문 테이블을 등록할 수 있다.
- [ ] 주문 테이블의 이용 여부를 수정할 수 있다.
- [ ] 주문 테이블의 이용 인원을 수정할 수 있다.
- [ ] 주문 테이블을 조회할 수 있다.
- [ ] 빈 테이블만 이용할 수 있다.

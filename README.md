# 키친포스

## 퀵 스타트

```sh
cd docker
docker compose -p kitchenpos up -d
```

## 요구 사항
- 상품과 메뉴를 등록하고 주문하는 키친포스 시스템을 구현합니다.
### 상품
> 상품이란 판매될 수 있는 물건이나 음식등을 의미합니다.
> 
> 여기서는 음식이 상품이 될 수 있을 것입니다. (치킨, 피자 등등)
- [ ] 상품 등록 기능 - 상품 가격과 상품명을 입력하여 등록합니다.
  - [ ] 상품명과 가격을 필수로 입력받습니다.
  - [ ] 상품명이 없거나 비속어가 있으면 안됩니다.
  - [ ] 가격은 0원 이상이어야 하며, 없거나 0원보다 작으면 안됩니다. 
- [ ] 가격 변경 기능 - 상품의 가격을 변경할 수 있습니다.
  - [ ] 등록되어 있는 상품의 id와 변경할 상품 정보(상품명, 가격, id)를 입력받습니다.
  - [ ] 변경할 상품의 가격은 0원이상이고, 없거나 0원 미만이 되면 안됩니다.
  - [ ] 상품 id는 등록되어 있는 상품이어야 합니다.
  - [ ] 메뉴의 상품들(동일 상품일수도 있고, 다른 상품일 수도 있습니다.) 
  의 총 가격 합이 메뉴의 가격보다 크면, 유효하지 않습니다.
  - [ ] 유효하지 않은 메뉴는 화면에서 노출하지 않습니다.
-[ ] 모든 상품을 조회할 수 있습니다.
- 

### 메뉴
> 메뉴란 음식점에서 실제로 소비자에게 제안되는 상품들을 목록화한 것입니다. 
>
> 상품개별이 될 수도, 여럿이 될 수도 있습니다.
> 
> ex : 치킨 + 콜라, 치킨 + 피자

- [ ] 메뉴 등록 기능 
  - [ ] 메뉴의 가격은 0이상이어야 하고, 없거나 0 미만은 안됩니다.
  - [ ] 메뉴는 반드시 1개의 메뉴그룹을 가지고 있어야 합니다.
  - [ ] 메뉴는 단일 이거나 동일,별개의 상품들을 조합해서 만들 수 있습니다.
  - [ ] 메뉴는 상품과 그 상품의 수량을 선택할 수 있습니다.
  - [ ] 메뉴는 반드시 상품이 1개이상 존재해야 합니다.
  - [ ] 메뉴 내부 상품의 수량은 0이 되면 안됩니다.
  - [ ] 메뉴를 구성하는 상품은 등록되어 있어야 합니다.
  - [ ] 등록하려는 메뉴의 가격이 메뉴에 포함된 상품의 총 가격보다 높으면 안됩니다.
  - [ ] 메뉴의 이름이 없거나 비속어가 들어가 있으면 안됩니다.

- [ ] 메뉴 가격 수정 기능
  - [ ] 수정 메뉴의 가격은 0이상이어야 하고, 없거나 0 미만은 안됩니다.
  - [ ] 수정 하려는 메뉴는 이미 등록이 되어 있는 메뉴여야 합니다.
  - [ ] 메뉴에 포함된 상품들의 가격 합보다 수정하려는 금액이 크면 안됩니다.

- [ ] 메뉴 노출 기능
  - [ ] 노출 요청하는 메뉴가 이미 등록되어 있는 메뉴여야 합니다
  - [ ] 메뉴내 포함된 금액의 합이 메뉴 금액보다 커서는 안됩니다
  - [ ] 메뉴 노출을 활성화 시킵니다.
-[ ] 메뉴 숨김 기능
  - [ ] 숨기려는 메뉴는 이미 존재하는 메뉴여야 합니다.
  - [ ] 메뉴 노출을 비활성화 합니다.
- [ ] 모든 메뉴 찾기 기능
  - [ ] 등록되어 있는 모든 메뉴를 조회합니다.

# 키친포스

## 퀵 스타트

```sh
cd docker
docker compose -p kitchenpos up -d
```

## 요구 사항

상품과 메뉴를 등록하고 주문을 처리하는 키친 포스 시스템을 개발합니다.

### 1. 상품

```
- '상품'은 사장님이 등록한 상품 정보를 의미합니다.
```

- [ ] 사장님은 '상품명'과 '상품 가격' 정보를 통해 '상품'을 등록할 수 있습니다.
    - [ ] '상품명'은 1자 이상이어야 합니다.
    - [ ] '상품명'에는 비속어나 욕설을 사용할 수 없으며, 외부 시스템을 통해서 검증합니다.
    - [ ] '상품 가격'은 0원 이상이어야 합니다.
- [ ] 사장님은 '상품 가격'을 변경할 수 있습니다.
    - [ ] '상품 가격'은 0원 이상이어야 합니다.
    - [ ] '상품'이 속한 '메뉴'의 '메뉴 가격'이 구성된 '상품'의 '상품 가격' 총합을 초과한 경우, '메뉴 노출 여부'가 '미노출 상태'로 변경됩니다.

### 2. 메뉴 그룹

```
- '메뉴 그룹'은 고객이 주문할 수 있는 메뉴의 집합을 의미합니다.
```

- [ ] 사장님은 '메뉴 그룹명' 정보를 통해 '메뉴 그룹'을 등록할 수 있습니다.
    - [ ] '메뉴 그룹명'은 1자 이상이어야 합니다.

### 3. 메뉴

```
- '메뉴'는 고객이 주문할 수 있는 상품의 집합을 의미합니다.
```

- [ ] 사장님은 '메뉴명', '메뉴 가격', '메뉴 그룹', '메뉴 상품(상품, 수량)', '메뉴 노출 여부'를 통해 메뉴를 등록할 수 있습니다.
    - [ ] '메뉴명'은 1자 이상이어야 합니다.
    - [ ] '메뉴명'에는 비속어나 욕설을 사용할 수 없으며, 외부 시스템을 통해서 검증합니다.
    - [ ] '메뉴 상품'의 수량은 0개 이상이어야 합니다.
    - [ ] '메뉴 가격'은 0원 이상이어야 하며, 메뉴를 구성한 '메뉴 상품'들의 '상품 가격' 합을 초과할 수 없습니다.
- [ ] 사장님은 '메뉴 가격'을 변경할 수 있습니다.
    - [ ] '메뉴 가격'은 0원 이상이어야 하며, 메뉴를 구성한 '메뉴 상품'과 연관된 '상품'의 '상품 가격' 합을 초과할 수 없습니다.
- [ ] 사장님은 '메뉴 노출 여부'를 변경할 수 있습니다.
    - [ ] '메뉴'를 구성하는 '상품'의 '상품 가격' 총합과 상관없이 '메뉴 노출 여부'를 '미노출 상태'로 변경할 수 있습니다.
    - [ ] '메뉴 가격'이 메뉴를 구성한 '메뉴 상품'과 연관된 '상품'의 '상품 가격' 합을 초과하지 않은 경우, '메뉴 노출 여부'를 '노출 상태'로 변경할 수 있습니다.

### 4. 주문

```
- '주문'은 고객이 가게에서 메뉴를 골라 주문을 하는 행위를 의미합니다.
- '주문 형식'은 '배달', '포장', '매장 식사'를 가집니다.
- '주문 항목'은 '메뉴'를 기반으로 생성한 정보이며 '메뉴'와 일치하는 정보를 가지고 있어야 합니다.
- '주문 상태는' '대기', '접수', '서빙', '배달 중', '배달 완료', '주문 완료' 를 가집니다.
    - '대기' - 주문이 생성된 상태
    - '접수' - 주문이 접수된 상태
    - '서빙' - 주문이 서빙될 수 있는 상태
        - 음식 조리가 완료되어 배달이나 매장 식사가 가능한 상태를 의미합니다.
    - '배달 중' - 주문이 배달 중인 상태
    - '배달 완료' - 주문이 배달 완료된 상태
    - '주문 완료' - 주문이 완료된 상태
- '주문 형식'별 '주문 상태' 흐름도는 다음과 같습니다.
    - 베달 : '대기' -> '접수' -> '서빙' -> '배달 중' -> '배달 완료' -> '주문 완료'
    - 포장 혹은 매장 식사 : '대기' -> '접수' -> '서빙' -> '주문 완료'
```

- [ ] 고객은 '주문 형식', '주문 항목 목록(주문 항목: 메뉴, 수량)', '배달 주소', '주문 테이블' 정보를 통해 주문을 생성할 수 있습니다.
    - [ ] '주문 형식'이 '배달' 또는 '포장'일 때, 각각의 '주문 항목 수량'은 0개 이상이어야 합니다.
    - [ ] '주문 형식'이 '매장 식사'일 때, 각각의 '주문 항목 수량'은 정수이어야 합니다.
    - [ ] '주문 항목 목록'에서 각 '주문 항목'의 '상품'의 '상품 가격'과 연관된 '메뉴'의 '메뉴 가격'이 일치해야 합니다.
    - [ ] '주문 항목 목록'에서 각 '주문 항목'과 연관된 '메뉴'의 '메뉴 노출 여부'가 노출 상태이어야 합니다.
    - [ ] '주문 형식'은 '배달', '포장' 또는 '매장 식사'이어야 합니다.
        - [ ] '주문 형식'이 '배달'일 경우, '배달 주소'는 필수 정보이며 1자 이상이어야 합니다.
        - [ ] '주문 형식'이 '매장 식사'일 경우, '주문 테이블'은 필수 정보이며 고객이 해당 테이블을 사용하고 있어야 합니다.
- [ ] 사장님은 '주문'의 '주문 상태'를 '접수' 상태로 변경할 수 있습니다.
    - [ ] '주문'을 접수하면 '주문 상태'가 '접수' 상태로 변경됩니다.
    - [ ] '주문 상태'가 '대기 상태'이어야만 '접수' 상태로 변경할 수 있습니다.
    - [ ] '주문 형식'이 '배달'일 경우, '주문 정보', '주문 금액', '배달 주소'를 통해 '배달 대행 업체'에게 배달을 요청합니다.
- [ ] 사장님은 '주문'의 '주문 상태'를 '서빙' 상태로 변경할 수 있습니다.
    - [ ] '주문'을 서빙하면 '주문 상태'가 '서빙' 상태로 변경됩니다.
    - [ ] '주문 상태'가 '접수' 상태이어야만 '서빙' 상태로 변경할 수 있습니다.
- [ ] 사장님은 '주문'의 '주문 상태'를 '배달중' 상태로 변경할 수 있습니다.
    - [ ] '주문'을 배달 완료하면 '주문 상태'가 '배달 완료' 상태로 변경됩니다.
    - [ ] '주문 형식'이 '배달'일 때 '주문 상태'가 '서빙' 상태이어야만 '배달 완료' 상태로 변경할 수 있습니다.
- [ ] 사장님은 '주문'의 '주문 상태'를 '배달 완료' 상태로 변경할 수 있습니다.
    - [ ] '주문'을 배달 완료하면 '주문 상태'가 '배달 완료' 상태로 변경됩니다.
    - [ ] '주문 형식'이 '배달'일 때 '주문 상태'가 '배달 중' 상태이어야만 '배달 완료' 상태로 변경할 수 있습니다.
- [ ] 사장님은 '주문'의 '주문 상태'를 '완료' 상태로 변경할 수 있습니다.
    - [ ] '주문'을 완료하면 '주문 상태'가 '주문 완료' 상태로 변경됩니다.
    - [ ] '주문 형식'이 '배달'일 때 '주문 상태'가 '배달 완료' 상태이어야만 '주문 완료' 상태로 변경할 수 있습니다.
    - [ ] '주문 형식'이 '매장 식사' 또는 '포장'일 때 '주문 상태'가 '서빙' 상태이어야만 '주문 완료' 상태로 변경할 수 있습니다.
    - [ ] '주문 형식'이 '매장 식사'이면서 '주문 상태'가 '주문 완료' 상태로 변경될 경우,     
      해당 '주문 테이블'의 '주문 테이블 상태'를 '비어있음'으로 변경하고 '손님 수'를 0명으로 변경할 수 있습니다.

### 5. 주문 항목

```
- '주문 항목'은 주문 시점에 주문한 메뉴와 수량을 의미합니다.
```

- [ ] 내부 시스템은 '메뉴', '수량' 정보를 통해 주문 시점에 '주문 항목'을 생성할 수 있습니다.
- [ ] '주문 형식'이 '배달' 또는 '포장'일 경우, 각각의 '주문 항목 수량'은 0개 이상이어야 합니다.

### 6. 주문 테이블

```
- '주문 테이블'은 '매장 식사' 고객이 주문을 할 수 있는 테이블을 의미합니다.
```

- [ ] 사장님은 '테이블 이름' 정보를 통해 '주문 테이블'을 등록할 수 있으며 '비어있음' 상태 및 '손님 수'가 0명으로 등록됩니다.
    - [ ] '테이블 이름'은 1자 이상이어야 합니다.
- [ ] 사장님은 '주문 테이블'의 '주문 테이블 상태'를 '비어있지 않음' 상태로 변경할 수 있습니다.
    - [ ] 사장님은 '주문 테이블'의 '손님 수'를 변경할 수 있습니다.
        - [ ] '손님 수'는 0명 이상이어야 합니다.
        - [ ] '주문 테이블'의 '주문 테이블 상태'가 '비어있지 않음'이어야 합니다.
- [ ] 사장님은 '주문 형식'이 '매장 식사'이면서 '주문 상태'가 '주문 완료' 상태일 때,   
  '주문 테이블 상태'를 '비어있음'으로 변경 및 '손님 수'를 0명으로 변경할 수 있습니다.

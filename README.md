# 키친포스

## 요구사항
배달 & 테이블 주문이 가능한 식당의 포스기 기능을 구현한다. 

### 상품
- 상품을 생성할 수 있다.
- 상품을 생성할 때 아래의 정보가 필요하다.
  - 상품명
  - 상품 가격
- 상품의 가격을 수정할 수 있다.
- 상품 목록을 조회할 수 있다.

### 메뉴 그룹
- 메뉴 그룹을 생성할 수 있다.
- 메뉴 그룹을 생성할 때 다음의 정보가 필요하다
  - 메뉴 그룹 이름
- 메뉴 그룹을 조회할 수 있다.

### 메뉴
- 메뉴를 생성할 수 있다
- 메뉴를 생성할 때 아래의 정보가 필요하다
  - 이름
  - 가격
  - 메뉴 그룹 ID
  - 노출 여부
  - 메뉴 상품 목록
  - 메뉴 상품에는 아래의 정보가 필요하다
    - 상품 ID
    - 개수
- 메뉴 가격을 수정할 수 있다.
- 메뉴를 숨길 수 있다.
- 메뉴를 노출할 수 있다.
- 메뉴 목록을 조회할 수 있다.

### 주문 테이블
- 주문 테이블을 생성할 수 있다.
- 주문 테이블을 생성할 때 아래의 정보가 필요하다.
  - 테이블 번호
- 주문 테이블의 상태를 아래와 같이 수정할 수 있다.
  - 고객 착석
  - 테이블 청소 완료
- 주문 테이블에 고객 수를 수정할 수 있다.
- 주문 테이블 목록을 조회할 수 있다.

### 주문
- 주문을 생성할 수 있다.
- 주문을 생성할 때 아래의 정보가 필요하다.
  - 주문 타입
  - 주문 테이블 ID
  - 주문 상품 목록
  - 주문 상품에는 아래의 정보가 필요하다
    - 메뉴 id
    - 가격
    - 개수
- 주문의 상태를 아래와 같이 수정할 수 있다.
  - 주문 수락
  - 조리 완료
  - 배달 시작
  - 배달 완료
  - 주문 완료
- 주문 목록을 조회할 수 있다.

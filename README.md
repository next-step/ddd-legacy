# 키친포스

## 퀵 스타트

```sh
cd docker
docker compose -p kitchenpos up -d
```

## 요구 사항
### 상품
- [ ] 상품은 상품 이름을 가지며, 가져야만 한다.
- [ ] 상품은 상품 가격을 가지며, 가져야만 한다.
### 메뉴
- [ ] 메뉴는 메뉴 이름을 가지며, 가져야만 한다.
- [ ] 메뉴는 메뉴 가격을 가지며, 가져야만 한다.
- [ ] 메뉴는 메뉴 표출 여부를 가지며, 가져야만 한다.
- [ ] 하나의 메뉴는 여러 메뉴 구성 상품들을 포함할 수 있다.
- [ ] 하나의 메뉴는 여러 주문 항목들에 포함될 수 있다.
### 메뉴 구성 상품
- [ ] 메뉴 구성 상품은 수량을 가지며, 가져야만 한다.
### 메뉴 그룹
- [ ] 메뉴 그룹은 메뉴 그룹 이름을 가지며, 가져야만 한다.
- [ ] 하나의 메뉴 그룹에는 여러 메뉴들이 포함될 수 있다.
### 주문
- [ ] 주문은 배달 주문, 포장 주문, 매장 주문 타입을 가지며, 가져야만 한다.
- [ ] 주문은 주문 대기, 주문 확인, 주문 준비 완료, 주문 배달 중, 주문 배달 완료, 주문 완료 상태를 가지며, 가져야만 한다.
- [ ] 주문은 주문 시각을 가지며, 가져야만 한다.
- [ ] 주문은 배달 주소를 가진다.
- [ ] 하나의 주문은 여러 주문 항목들을 포함할 수 있다.
### 주문 항목
- [ ] 주문 항목은 수량을 가지며, 가져야만 한다.
### 주문 테이블
- [ ] 주문 테이블은 테이블 이름을 가지며, 가져야만 한다.
- [ ] 주문 테이블은 손님 수를 가지며, 가져야만 한다.
- [ ] 주문 테이블은 사용 중 여부를 가지며, 가져야만 한다.
- [ ] 하나의 주문 테이블에서는 여러 주문들이 포함될 수 있다.
### 상픔 관리
- [ ] 상품을 등록할 수 있다.
- [ ] 상품의 가격을 수정할 수 있다.
- [ ] 모든 상품들을 조회할 수 있다.
- [ ] 상품의 가격은 0이거나, 0보다 커야한다.
- [ ] 상품의 이름은 입력하지 않거나, 부적절한 표현을 포함할 수 없다.
- [ ] 미등록 상품에 대한 조회 시도는 예외 처리한다.
- [ ] 상품 가격 수정 시 해당 상품을 포함하는 메뉴들에 수정한 상품 가격이 반영되도록 한다.
### 메뉴 관리
- [ ] 메뉴를 생성할 수 있다.
- [ ] 메뉴의 가격을 수정할 수 있다.
- [ ] 메뉴의 표출하도록 할 수 있다.
- [ ] 메뉴를 표출하지 않도록 할 수 있다.
- [ ] 모든 메뉴들을 조회할 수 있다.
- [ ] 메뉴의 가격이 메뉴 구성 상품 가격의 합보다 큰 경우 해당 메뉴를 미표출 처리한다.
- [ ] 메뉴의 가격은 0이거나, 0보다 커야한다.
- [ ] 메뉴는 기존에 등록되어 있는 메뉴 그룹에만 등록할 수 있다.
- [ ] 메뉴는 1개 이상의 메뉴 구성 상품을 가져야 한다.
- [ ] 메뉴에 포함될 메뉴 구성 상품의 수량은 0이거나, 0보다 커야한다.
- [ ] 기존에 등록되어 있는 상품만 메뉴에 포함될 수 있다.
- [ ] 메뉴 구성 상품 금액의 합과 메뉴의 금액은 일치해야 한다.
- [ ] 메뉴의 이름은 입력하지 않거나, 부적절한 표현을 포함할 수 없다.
- [ ] 미등록 메뉴에 대한 조회 시도는 예외 처리한다.
### 메뉴 그룹 관리
- [ ] 메뉴 그룹을 등록할 수 있다.
- [ ] 모든 메뉴 그룹들을 조회할 수 있다.
- [ ] 메뉴 그룹의 이름은 입력하지 않거나 공백일 수 없다.
### 주문 관리
- [ ] 주문을 등록할 수 있다.
- [ ] 주문을 주문 확인 상태로 변경할 수 있다.
- [ ] 주문을 주문 준비 완료 상태로 변경할 수 있다.
- [ ] 주문을 주문 배달 중 상태로 변경할 수 있다.
- [ ] 주문을 주문 배달 완료 상태로 변경할 수 있다.
- [ ] 주문을 주문 완료 상태로 변경할 수 있다.
- [ ] 모든 주문들을 조회할 수 있다.
- [ ] 주문은 1개 이상의 주문 항목을 가져야 한다.
- [ ] 하나의 주문에서 주문 항목의 수와 주문 항목이 포함하는 메뉴의 수는 일치해야 한다.
- [ ] 포장 주문, 배달 주문인 경우 주문에 포함될 주문 항목의 수량은 0이거나, 0보다 커야한다.
- [ ] 기존에 등록되어 있는 메뉴만 주문 항목에 포함될 수 있다.
- [ ] 주문 항목에 포함될 메뉴가 미표출 상태인 경우 예외 처리한다.
- [ ] 주문 항목의 가격과 주문 항목이 포함하는 메뉴의 가격은 일치해야 한다.
- [ ] 배달 주문인 경우 배달 주소는 입력하지 않거나 공백일 수 없다.
- [ ] 기존에 등록되어 있는 주문 테이블에만 주문을 할당할 수 있다.
- [ ] 사용 중인 주문 테이블에는 주문을 할당할 수 없다.
- [ ] 미등록 주문에 대한 조회 시도는 예외 처리한다.
- [ ] 주문 확인 상태 변경 시도 시, 주문이 주문 대기 상태가 아니라면 예외 처리한다.
- [ ] 배달 주문인 경우 주문 확인 시점에 배달 요청을 외부시스템으로 전송한다.
- [ ] 주문 준비 완료 상태 변경 시도 시, 주문이 주문 확인 상태가 아니라면 예외 처리한다.
- [ ] 주문 배달 중 상태 변경 시도 시, 주문 타입이 배달 주문이 아니라면 예외 처리한다.
- [ ] 주문 배달 중 상태 변경 시도 시, 주문이 주문 준비 완료 상태가 아니라면 예외 처리한다.
- [ ] 주문 배달 완료 상태 변경 시도 시, 주문이 주문 배달중 상태가 아니라면 예외 처리한다.
- [ ] 주문 완료 상태 변경 시도 시, 배달 주문인 경우 주문 배달 완료 상태가 아니라면 예외 처리한다.
- [ ] 주문 완료 상태 변경 시도 시, 포장 주문이거나 매장 주문인 경우 주문 준비 완료 상태가 아니라면 예외 처리한다.
- [ ] 주문 완료 상태 변경 시도 시, 매장 주문인 경우 주문이 포함되는 주문 테이블의 손님 수를 0으로 수정하며, 사용 중 여부를 사용 중이지 않음으로 수정한다.
### 주문 테이블 관리
- [ ] 주문 테이블을 등록할 수 있다.
- [ ] 주문 테이블의 사용 중 여부를 사용 중으로 변경할 수 있다.
- [ ] 주문 테이블을 초기화 할 수 있다.
- [ ] 주문 테이블의 손님 수를 수정할 수 있다.
- [ ] 모든 주문 테이블들을 조회할 수 있다.
- [ ] 주문 테이블의 이름은 입력하지 않거나, 공백일 수 없다.
- [ ] 미등록 주문 테이블에 대한 조회 시도는 예외 처리한다.
- [ ] 초기화 하고자 하는 주문 테이블의 주문 상태가 주문 완료가 아니라면 예외 처리한다.
- [ ] 주문 테이블을 초기화 하는 경우 주문 테이블의 손님 수를 0으로 수정하며, 사용 중 여부를 사용 중이지 않음으로 수정한다.
- [ ] 주문 테이블 손님 수 수정 시도 시, 손님 수는 0이거나 0보다 커야한다.
- [ ] 주문 테이블 손님 수 수정 시도 시, 해당 주문 테이블의 사용 중 여부는 사용 중이어야 한다.
### 외부 시스템
- [ ] 외부 시스템으로 배달을 요청할 수 있다.
- [ ] 외부 시스템으로 글에 부적절한 표현 포함 여부 확인을 요청할 수 있다.


## 용어 사전

| 한글명      | 영문명 | 설명                                      |
|----------|------------|-----------------------------------------|
| 상품       | Product | '메뉴'의 구성 요소                             |
| 메뉴       | Menu | '메뉴 그룹'의 구성 요소                          |
| 메뉴 그룹    | MenuGroup  | 여러 메뉴가 속할 수 있는 그룹                       |
| 주문       | Order      |                                         |
| 주문 항목    | OrderLineItem | '주문'에서 메뉴와 주문된 수량을 다루기 위한 개념            |
| 주문 테이블   | OrderTable | 매장 주문 시 여러 '주문'이 포함되며 손님이 실제 사용 하는 개념   |
| 주문 대기    |WAITING| 가게에서 주문을 확인 하지 않은 상태를 의미                |
| 주문 확인    |ACCEPTED| 가게에서 주문을 확인하여 준비 중인 상태를 의미              |
| 주문 준비 완료 |SERVED| 가게에서 주문을 준비 완료하여 손님에게 전달할 준비를 마친 상태를 의미 |
| 주문 배달 중  |DELIVERING| 손님의 주문이 배달 중인 상태를 의미                    |
| 주문 배달 완료 |DELIVERED| 손님의 주문이 배달 완료된 상태를 의미                   |
| 주문 완료    |COMPLETED| 손님의 주문이 모두 완료 처리된 상태를 의미                |
| 배달 주문    |DELIVERY| 주문의 종류 중 배달 주문을 의미                      |
| 포장 주문    |TAKEOUT| 주문의 종류 중 포장 주문을 의미                      |
| 매장 주문    |EAT_IN| 주문의 종류 중 매장 주문을 의미                      |

# 키친포스

## 퀵 스타트

```sh
cd docker
docker compose -p kitchenpos up -d
```

## 요구 사항

- 가게에서 상품과 메뉴를 등록하고 이를 주문하는 키친 포스 시스템을 구현합니다.

    1. 상품
        1) 상품은 상품명과 상품가격을 통해 등록한다.
            - 상품가격은 0원 이상이어야 한다.
            - 상품명은 외부 검증을 통해 욕설이나 외설성이 있으면 안된다.
            - 상품명은 1글자 이상이어야 한다.
            - 위의 조건이 모두 적합하다면 상품명과 상품가격에 맞는 `상품 id`를 생성하고 이 `상품정보`를 등록한다.
        2) 상품가격은 변경이 가능하다.
            - 상품가격은 0원 이상이어야 한다.
            - 상품 id를 통해 등록된 상품정보를 가져옵니다.
            - 가져온 상품정보의 상품가격을 변경합니다.
            - 상품 id를 통해 현재 변경된 상품정보를 갖고 있는 메뉴를 전부 가져옵니다.
            - 가져온 모든 메뉴에서 변경된 상품가격들의 총합이 메뉴의 가격보다 낮으면 메뉴를 더 이상 보이지 않게 합니다.

    2. 메뉴 그룹
        1) 메뉴 그룹은 메뉴그룹명을 통해 등록한다.
           - 메뉴그룹명은 1글자 이상이어야 한다.
           - 위 조건이 적합하다면 메뉴그룹명과 이에 맞는 `메뉴그룹 id`를 생성하고 이 `메뉴그룹정보`를 등록한다.

    3. 메뉴
        - [ ]  몬스터볼은 고유의 보정 승수를 가지고 있다.
          (몬스터볼: 1.0, 수퍼볼: 1.5, 하이퍼볼: 2.0, 마스터볼: 255)
    4. 주문
        - [ ]  사용자는 트레이너라고 부른다.
    5. 주문한 테이블
        - [ ]  사용자는 트레이너라고 부른다.

## 용어 사전

| 한글명    | 영문명           | 설명                                       |
|--------|---------------|------------------------------------------|
| 상품 id  | ProductId     | 상품명과 상품가격에 매칭되는 상품 정보의 고유 값 혹은 번호        |
| 상품정보   | ProductInfo   | 상품 id, 상품명, 상품가격으로 구성되어 저장하는 상품의 정보들의 집합 |
| 메뉴그룹 id | MenuGroupId   | 메뉴그룹명에 매칭되는 메뉴그룹 정보의 고유 값 혹은 번호          |
| 메뉴그룹정보 | MenuGroupInfo | 메뉴그룹 id, 메뉴그룹명 구성되어 저장하는 메뉴그룹의 정보들의 집합   |

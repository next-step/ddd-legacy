# 키친포스

## 퀵 스타트

```sh
cd docker
docker compose -p kitchenpos up -d
```

## 요구 사항

- 메뉴를 판매 할 수 있는 포스 시스템을 만든다.
- 상품(Product)
    - [ ] 상품은 상품명, 가격을 가진다.
    - [ ] 상품을 등록 할 수 있다.
      - [ ] 상품의 이름 및 가격은 필수요청 값 이다.
      - [ ] 상품 이름에는 비속어를 넣을 수 없다.
      - [ ] 가격은 0보다 큰 값이어야 한다.
    - [ ] 상품을 조회 할 수 있다.
    - [ ] 상품의 가격을 변경 할 수 있다.
      - [ ] 메뉴의 가격이 메뉴에 속한 제품들의 총 가격(가격 곱하기 수량의 합)보다 클 경우 숨김 처리 한다.
- 메뉴그룹
    - [ ] 메뉴그룹은 메뉴의 분류를 나타낸다.
    - [ ] 메뉴그룹을 등록 할 수 있다.
      - [ ] 메뉴그룹의 이름은 필수요청 값 이다.
    - [ ] 메뉴그룹을 조회 할 수 있다.
- 메뉴
    - [ ] 메뉴는 메뉴명, 가격, 메뉴그룹, 제품목록, 노출여부을 가진다.
    - [ ] 메뉴를 등록 할 수 있다.
      - [ ] 메뉴의 이름, 가격, 메뉴그룹, 상품목록(최소 1개)은 필수 값 이다.
      - [ ] 메뉴의 이름에는 비속어를 넣을 수 없다.
      - [ ] 가격은 0원보다 큰 값이어야 한다.
      - [ ] 제품의 수량은 0개보다 큰 값이어야 한다.
      - [ ] 메뉴의 가격은 메뉴에 속한 제품들의 총 가격(가격 곱하기 수량의 합)보다 클 수 없다.
    - [ ] 메뉴를 조회 할 수 있다.
    - [ ] 메뉴의 가격을 변경 할 수 있다.
      - [ ] 메뉴의 가격은 0보다 큰 값이어야 한다. 
      - [ ] 메뉴의 가격은 메뉴에 속한 제품들의 총 가격(가격 곱하기 수량의 합)보다 클 수 없다.
    - [ ] 메뉴을 숨김 처리 할 수 있다.
    - [ ] 메뉴을 노출 처리 할 수 있다.
      - [ ] 메뉴의 가격이 메뉴에 속한 제품들의 총 가격(가격 곱하기 수량의 합)보다 클 경우 노출 처리 할 수 없다.
  - 주문
    - [ ] 주문은 주문번호, 주문테이블, 주문상태, 주문항목, 주문시간, 배송주소를 가진다.
    - [ ] 주문 목록을 조회 할 수 있다.
    - [ ] 주문을 등록 할 수 있다.
      - [ ] 주문의 주문방법(매장, 테이크아웃, 배달), 주문항목(최소 1개)은 필수 값 이다.
      - [ ] 주문의 주문항목은 메뉴와 수량, 가격을 가진다.
      - [ ] 주문에 대해 검증한다.
        - [ ] 매장 주문이 아닐 경우 주문의 주문항목의 수량은 0보다 큰 값이어야 한다.
        - [ ] 주문항목의 메뉴는 노출되어 있지 않거나, 요청 금액과 메뉴의 가격이 다를 경우 주문을 등록 할 수 없다.
      - [ ] 배달 주문일 경우
         - [ ] 주소는 필수요청 값 이다.
      - [ ] 매장 주문일 경우
         - [ ] 주문 테이블은 필수요청 값 이다.
         - [ ] 해당 테이블에 착석이 되어 있어야 한다.
    - [ ] 주문을 접수 할 수 있다.
       - [ ] 대기 상태가 아닌 주문은 처리 할 수 없다.
       - [ ] 배달 주문일 경우
         - [ ] 라이더에게 배달 요청을 한다.
       - [ ] 주문을 접수하면 주문 상태가 접수로 변경된다.
    - [ ] 주문을 서빙 할 수 있다.
       - [ ] 접수 상태가 아닌 주문은 처리 할 수 없다.
       - [ ] 주문을 서빙하면 주문 상태가 서빙으로 변경된다.
    - [ ] 주문의 배달을 시작 할 수 있다.
       - [ ] 접수 상태가 아닌 주문은 처리 할 수 없다.
       - [ ] 주문 방법이 배달이 아닌 경우 처리 할 수 없다.
       - [ ] 주문을 배달하면 주문 상태가 배달중으로 변경된다.
    - [ ] 주문의 배달을 완료 할 수 있다.
       - [ ] 배달중 상태가 아닌 주문은 처리 할 수 없다.
       - [ ] 주문을 배달하면 주문 상태가 배달완료로 변경된다.
    - [ ] 주문을 완료 할 수 있다.
       - [ ] 배달 주문일 경우
         -  [ ] 배달완료 상태가 아닌 주문은 처리 할 수 없다.
       - [ ] 이외의 주문은 서빙 상태가 아닌 주문은 처리 할 수 없다.
       - [ ] 매장 주문일 경우
         - [ ] 해당주문의 테이블의 주문이 남아있지 않은 경우 테이블을 비운다.
       - [ ] 주문 상태가 완료로 변경된다.
    - [ ] 주문 타입별 주문의 순서
      - [ ] 매장 주문, 포장일 경우 : 대기 -> 접수 -> 서빙 -> 완료
      - [ ] 배달 주문일 경우  : 대기 -> 접수 -> 배달중 -> 배달완료 -> 완료
  - 테이블
    - [ ] 테이블은 테이블 이름, 인원수, 착석여부를 가진다.
    - [ ] 테이블을 등록 할 수 있다.
      - [ ] 테이블의 이름은 필수요청 값 이다.
    - [ ] 테이블을 조회 할 수 있다.
    - [ ] 테이블의 인원수를 변경 할 수 있다.
      - [ ] 테이블의 인원수는 0명보다는 큰 값이어야 한다.
      - [ ] 테이블이 미착석인 경우에는 인원수를 변경 할 수 없다.
    - [ ] 테이블을 착석 할 수 있다.
    - [ ] 테이블을 비울 수 있다.
      - [ ] 해당 테이블에 완료되지 않은 주문이 남아 있을 경우 테이블을 비울 수 없다.
      - [ ] 인원수를 0명으로 변경한다.
      - [ ] 착석여부를 미착석으로 변경한다.

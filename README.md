# 키친포스

## 퀵 스타트

```sh
cd docker
docker compose -p kitchenpos up -d
```

## 요구 사항
- 메뉴 그룹(Menu Group)
  - 기능
    - [ ] 메뉴 그룹을 모두 조회한다
    - [ ] 메뉴 그룹을 생성한다
  - 정책
    - [ ] 메뉴 그룹의 이름은 필수값이다
- 메뉴(Menu)
  - 기능
    - [ ] 메뉴를 모두 조회한다
    - [ ] 메뉴를 생성한다
    - [ ] 메뉴의 가격을 변경한다
    - [ ] 메뉴가 보이게 한다
    - [ ] 메뉴를 숨긴다
  - 정책
    - [ ] 이름은 필수값이며 욕설 필터링을 통과해야한다
    - [ ] 가격은 필수값이고 0원 초과이다
    - 상위 메뉴그룹
      - [ ] 메뉴 그룹은 필수값이며 1개이다
    - 포함된 프로덕트들
      - [ ] 프로덕트를 1개 이상 가져야 하며 중복될 수 없다
      - [ ] 가격은 포함된 프로덕트들의 가격의 합 보다 커야한다
      - [ ] 각 프로덕트들의 재고는 0개 초과 여야 한다
- 프로덕트(Product)
  - 기능
    - [ ] 프로덕트를 모두 조회한다
    - [ ] 프로덕트를 생성한다
    - [ ] 프로덕트의 가격을 변경한다
  - 정책
    - [ ] 이름은 필수값이며 욕설 필터링을 통과해야한다
    - [ ] 가격은 필수값이고 0원 초과이다
    - 상위 메뉴들
      - [ ] 메뉴가격이 포함된 프로덕트들의 가격의 합 보다 작다면 메뉴가 보이지 않게 된다
- 주문 테이블(OrderTable)
  - 기능
    - [ ] 주문 테이블을 모두 조회한다
    - [ ] 주문 테이블을 생성한다
    - [ ] 주문 테이블에 손님이 앉는다
    - [ ] 주문 테이블에 손님의 수를 변경한다
    - [ ] 주문 테이블을 비운다
  - 정책
    - [ ] 이름은 필수값이다
    - [ ] 주문이 완료여야만 비울 수 있다
    - [ ] 앉아있어야만 테이블의 고객 수를 변경할 수 있다
    - [ ] 테이블을 비울 때 테이블의 고객도 0명이다
- 주문
  - [ ] 주문의 타입은 필수값이다 (홀주문, 배달주문, 포장주문)
  - [ ] 주문은 최소 1개의 메뉴를 갖는다
  - [ ] 홀주문이 아니라면 각 메뉴는 1개 이상 주문해야 한다
  - [ ] 보이지 않는 메뉴는 주문할 수 없다
  - [ ] 배달주문이면 주소는 필수 값이다
  - [ ] 홀주문이라면 주문 테이블은 필수값이다
  - 주문 상태
    - [ ] 주문의 상태는 주문대기, 주문접수, 서빙완료, 배달중, 배달완료, 완료가 있다
    - [ ] 주문의 초기값은 주문대기 이다
    - [ ] 주문접수는 주문대기에서만 변경할 수 있다
    - [ ] 주문승인 시 배달주문은 배달라이더에 배달 요청을 해둔다
    - [ ] 서빙완료는 주문승인에서만 변경할 수 있다
    - [ ] 배달중은 배달주문이고 서빙완료일때만 변경할 수 있다.
    - [ ] 배달완료는 배달주문이고 배달중일때만 변경할 수 있다.
    - [ ] 완료는 배달주문인경우 배달완료, 홀주문이거나 포장주문인 경우 서빙완료일때만 변경할 수 있다.
    - [ ] 홀주문이 완료되면 주문 테이블의 고객을 0명 비어있는 상태로 변경한다

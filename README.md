# 키친포스

## 퀵 스타트

```sh
cd docker
docker compose -p kitchenpos up -d
```

## 요구 사항

- 가게에서 상품과 메뉴를 등록하고 이를 주문하는 키친 포스 시스템을 구현합니다.

    1. 상품
        1) 상품을 등록할 수 있다.
            - 상품가격은 0원 이상이어야 한다.
            - 상품명은 외부 검증을 통해 욕설이나 외설성이 있으면 안된다.
            - 상품명은 1글자 이상이어야 한다.
        2) 상품의 가격은 변경이 가능하다.
            - 상품가격은 0원 이상이어야 한다.
            - 상품은 주인이 등록한 상품만 수정 가능하다.
            - 메뉴에 있는 상품들의 가격의 총합이 메뉴의 전체 가격보다 낮으면 메뉴를 노출하지 않는다.
                - 메뉴에 있는 상품 A의 가격이 5000원, 상품 B의 가격이 6000원이라면 메뉴의 전체 가격은 11000원 보다 초과하면 더 이상 메뉴를 노출하지 않는다.
        3) 모든 상품을 조회할 수 있다.
            - 등록된 메뉴가 하나도 없다면 조회했을 때 아무 것도 뜨지 않는다.

    2. 메뉴 모음
        1) 메뉴 모음을 등록할 수 있다.
            - 메뉴 모음의 이름은 1글자 이상이어야 한다.
        2) 모든 메뉴 모음을 조회할 수 있다.
            - 등록된 메뉴 모음이 하나도 없다면 조회했을 때 아무 것도 뜨지 않는다.

    3. 메뉴
        1) 메뉴를 등록할 수 있다.
            - 메뉴의 가격은 0원 이상이어야 한다.
            - 메뉴 모음은 하나 이상의 메뉴로 구성되어야 한다.
            - 메뉴는 하나 이상의 상품으로 구성되어 있다.
            - 메뉴에 등록된 모든 상품은 이미 등록이 된 상품이어야 한다.
            - 메뉴를 구성하는 상품과 수량은 등록할 수 있다.
            - 메뉴의 전체 가격이 메뉴의 상품들의 전체 가격보다 크면 안된다.
                - 메뉴에 있는 상품 A의 가격이 5000원, 상품 B의 가격이 6000원이라면 메뉴의 전체 가격은 11000원 보다 초과하면 안된다.
            - 메뉴명은 1글자 이상이어야 한다.
        2) 메뉴의 가격은 변경이 가능하다.
            - 메뉴의 가격은 0원 이상이어야 한다.
            - 주인이 등록한 메뉴의 가격만 수정이 가능하다.
            - 메뉴에 등록된 상품들의 전체가격은 변경된 메뉴의 가격보다 크면 안된다.
                - 메뉴에 있는 상품 A의 가격이 5000원, 상품 B의 가격이 6000원이라면 메뉴의 전체 가격을 11000보다 적게 하면 안된다.
        3) 메뉴를 노출할 수 있다.
            - 주인이 등록한 메뉴만 노출할 수 있다.
            - 메뉴 상품들의 가격 합보다 메뉴 가격이 크면 메뉴를 노출할 수 없다.
                - 메뉴에 있는 상품 A의 가격이 5000원, 상품 B의 가격이 6000원이라면 메뉴의 전체 가격이 11000보다 적으면 메뉴를 노출할 수 없다.
        4) 메뉴를 노출하지 않을 수 있다.
            - 주인이 등록한 메뉴만 노출하지 않을 수 있다.
        5) 모든 메뉴를 조회할 수 있다.
            - 등록된 메뉴가 하나도 없다면 조회했을 때 아무 것도 뜨지 않는다.

    4. 주문
        1) 주문 등록
            - 주문 유형은 배달, 테이크아웃, 매장 중에 선택되어야 한다.
            - 주문 상품들은 존재해야만한다.
            - 주문 상품들은 존재하는 메뉴들이어야한다.
            - 주문 상품의 갯수와 이에 맞게 등록된 메뉴의 갯수는 동일해야 한다.
            - 주문 유형이 매장이 아니라면 주문상품의 갯수는 0보다 커야한다.
            - 주문의 메뉴는 존재해야하는 메뉴여야한다.
            - 메뉴의 가격과 주문메뉴의 가격은 같아야 한다.
            - 위의 조건을 모두 만족한다면 주문 상품들은 메뉴, 수량, 주문 상품으로 구성된다.
            - 처음 주문을 받으면 주문상태는 대기상태이다.
            - 주문 시간은 현재시간으로 한다.
            - 주문 유형이 배달일시 배달 주소는 필수적이다.
            - 주문 유형이 매장일시 매장내 가능한 주문 테이블이 존재해야 한다.
            - 위의 조건이 모두 만족한다면 이에 맞는 `주문id`를 생성하고 `주문`를 등록한다.
        2) 주문 수락
            - 주문 정보는 등록된 주문 정보여야한다.
            - 현재 주문상태가 대기상태여야한다.
            - 주문 유형이 배달이라면 배달원에게 주문 id, 배달주소, 주문상품들의 가격을 통해 배달 요청할 수 있다.
            - 배달 요청에 성공했다면 주문상태는 수락으로 변경된다.
        3) 서빙
            - 주문 정보는 등록된 주문 정보여야한다.
            - 현재 주문상태가 수락이면 안된다.
            - 주문 상태는 서빙됨으로 변경된다.
        4) 배달 시작
            - 주문 정보는 등록된 주문 정보여야한다.
            - 배달시작은 주문 유형이 배달일때만 가능하다.
            - 주문 상태가 서빙이면 안된다.
            - 위에 조건을 만족한다면 주문상태는 배달 중으로 변경된다.
        5) 배달 완료
            - 주문 정보는 등록된 주문 정보여야한다.
            - 주문상태가 배달 중이어야 한다.
            - 위 조건을 만족한다면 주문상태는 배달됨으로 변경된다.
        6) 주문 완료
            - 주문 정보는 등록된 주문 정보여야한다.
            - 주문 유형이 배달일 때, 주문 상태가 배달됨이 아니라면 주문이 완료되지 않았다.
            - 주문 유형이 테이크아웃이거나 매장일 때, 주문 상태가 서빙됨이 아니라면 주문이 완료되지 않았다.
            - 주문 유형이 매장일 때, 주문 테이블 상태가 전부 제공완료라면 주문 테이블의 인원을 0으로 변경하고 사용가능 상태로 변경한다.
        7) 주문 조회

    5. 주문 테이블
        1) 주문 테이블 등록
            - 주문 테이블명은 1글자 이상이어야 한다.
            - 주문 테이블의 인원은 0명으로 등록한다.
            - 주문 테이블의 상태는 사용가능으로 등록한다.
            - 위 상태를 모두 만족한다면 이에 맞는 `주문 테이블 id`를 생성하고 `주문 테이블`에 등록한다.
        2) 주문 테이블 착석
            - 주문 테이블 정보는 등록된 주문 테이블 정보여야한다.
            - 주문 테이블의 상태를 사용중으로 등록한다.
        3) 주문 테이블 청소
            - 주문 테이블 정보는 등록된 주문 테이블 정보여야한다.
            - 주문 테이블 상태가 전부 제공완료라면 주문 테이블의 인원을 0으로 변경하고 사용가능 상태로 변경한다.
        4) 주문 테이블 인원 변경
            - 주문 테이블 인원은 0명보다 많아야 한다.
            - 주문 테이블 정보는 등록된 주문 테이블 정보여야한다.
            - 주문 테이블 상태는 사용중여야 한다.
            - 주문 테이블 인원 정보를 변경한다.
        5) 주문 테이블 조회

## 용어 사전

| 한글명       | 영문명          | 설명                                                                    |
|-----------|--------------|-----------------------------------------------------------------------|
| 상품 id     | ProductId    | 상품명과 상품가격에 매칭되는 상품 정보의 고유 값 혹은 번호                                     |
| 상품        | Product      | 상품 id, 상품명, 상품가격으로 구성되어 저장하는 상품의 정보들의 집합                              |
| 메뉴그룹 id   | MenuGroupId  | 메뉴그룹명에 매칭되는 메뉴그룹 정보의 고유 값 혹은 번호                                       |
| 메뉴그룹      | MenuGroup    | 메뉴그룹 id, 메뉴그룹명 구성되어 저장하는 메뉴그룹의 정보들의 집합                                |
| 메뉴 id     | MenuId       | 메뉴에 매칭되는 메뉴 정보의 고유 값 혹은 번호                                            |
| 메뉴        | Menu         | 메뉴명, 메뉴가격, 메뉴그룹, 진열여부, 메뉴 상품, 메뉴 id로 구성되어 저장하는 메뉴의 정보들의 집합            |
| 주문 id     | OrderId      | 주문에 매칭되는 주문 정보의 고유 값 혹은 번호                                            |
| 주문        | Order        | 주문 유형, 주문상태, 주문시간, 주문상품들, 배달 주소, 주문 테이블, 주문 id로 구성되어 저장하는 주문의 정보들의 집합 |
| 주문 테이블 id | OrderTableId | 주문 테이블에 매칭되는 주문 테이블정보의 고유 값 혹은 번호                                     |
| 주문 테이블    | OrderTable   | 주문 테이블명, 주문 테이블상태, 주문 테이블 인원, 주문 테이블 id로 구성되어 저장하는 주문의 정보들의 집합        |

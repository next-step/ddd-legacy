```sh
cd docker

```

## 요구 사항
- 기존 레거시 키친포스를 리팩토링 한다.

****
### 1. 상품 (product)
  - [x] 상품은 상품명과, 금액을 필수로 가진다.
  - [ ] 상품명은 비속어를 포함할 수 없다.
  - [ ] 금액은 무조건 0원 이상이어야 한다.
  

  - API
    1. 상품 조회
       - [ ] 상품 조회시 특정 조건 없이 상품의 모든 목록을 조회할 수 있다.
       - [ ] 상품 조회시에 결과 수에 대한 제한이 필요하다.
    2. 상품 등록
       - [ ] 상품 등록시 상품명 및 금액의 유효성 검증을 한다. (비어있는지, 0이상인지, 욕설을 포함하는지)
       - [ ] 상품은 단건으로만 등록이 가능하다.
    3. 상품 수정 (금액 수정)
       - [ ] 상품 수정시 금액이 비어있는지 0이상인지 검증을 한다.
       - [ ] 상품 수정시 금액이 비어있는지 0이상인지 검증을 한다.
       - [ ] 해당 상품을 가진 메뉴의 가격이 메뉴 구성 상품보다 총합이 크면 해당 메뉴는 노출하지 않는다.

****
### 2. 메뉴 그룹 (menu group)
  - [x] 메뉴 그룹은 그룹명을 필수로 가진다.
  - [ ] 그룹명에 대한 유효성 확인필요
  

  - API
    1. 메뉴 그룹 조회
       - [ ] 메뉴 그룹 조회시 특정 조건 없이 모든 목록을 조회할 수 있다.
       - [ ] 메뉴 그룹 조회시에 결과 수에 대한 제한이 필요하다.
    2. 메뉴 그룹 등록
       - [ ] 메뉴 그룹명이 공란인지 유효성 검증한다.
  
****
### 3. 메뉴 상품 (menu product)
  - [x] 메뉴 상품은 수량과 상품 및 메뉴의 key 값을 필수로 가진다.
  - [x] 수량은 0이상 이어야 한다.
  
****
### 4. 메뉴 (menu)
  - [x] 메뉴는 메뉴명, 금액, 노출여부, 메뉴 그룹 key 값을 필수로 가진다.
  
  - API
     1. 메뉴 조회
        - [ ] 메뉴 조회시 특정 조건 없이 모든 목록을 조회할 수 있다.
        - [ ] 메뉴 조회시에 결과 수에 대한 제한이 필요하다.
     2. 메뉴 등록
        - [ ] 메뉴 가격은 비어있지않고 0이상 이어야 한다.  
        - [ ] 메뉴 그룹 key 가 존재해야 한다.
        - [ ] 등록하려는 메뉴 구성 정보가 있어야 하고 등록된 상품이어야 한다.
        - [ ] 메뉴명도 상품명처럼 비속어를 포함할 수 없다.
        - [ ] 등록하려는 메뉴 가격이 구성 상품의 합계보다 크지 않아야 한다.
     3. 메뉴 노출
        - [ ] 등록된 메뉴가 없으면 예외를 발생한다.
        - [ ] 등록된 메뉴의 가격이 메뉴 구성 상품보다 총합이 크면 예외를 발생한다.
     4. 메뉴 숨김
        - [ ] 등록된 메뉴가 없으면 예외를 발생한다.
     5. 메뉴 금액 변경
        - [ ] 변경하려는 가격이 비어있는지, 0보다 작은지 검증한다.
        - [ ] 변경하려는 가격이 메뉴 구성 상품 총합보다 크면 예외를 발생한다.
  
****
### 5. 주문 (orders)
  - [x] 주문상태, 주문유형, 주문시간을 필수로 가진다.
  
  - API
     1. 주문 조회
        - [ ] 주문 조회시 특정 조건 없이 모든 목록을 조회할 수 있다.
        - [ ] 주문 조회시에 결과 수에 대한 제한이 필요하다.
     2. 주문 등록
        - [ ] 주문 유형이 존재해야 한다.
        - [ ] 주문 아이템이 비어있으면 예외를 발생한다.
        - [ ] 주문 아이템에 있는 메뉴가 존재해야 한다.
        - [ ] 배달, 포장 주문시 수량이 0이상 이어야 한다.
        - [ ] 메뉴가 노출된 상태여야 한다.
        - [ ] 메뉴가격과 주문 아이템 가격이 다르면 예외를 발생한다.
        - [ ] 배달 주문시 배달 주소가 비어있지 않아야한다.
        - [ ] 메뉴가격과 주문 아이템 가격이 다르면 예외를 발생한다.
        - [ ] 먹고가기의 경우 테이블 주문내역이 있어야 한다.
     3. 주문 수락
        - [ ] 등록된 주문이 없으면 예외를 발생한다.
        - [ ] 현 주문상태가 **대기**가 아니면 예외를 발생한다.
        - [ ] 배달 주문인 경우, 주문 아이템 총합 계산하고 배달 요청한다.
     4. 서빙/준비 완료
        - [ ] 등록된 주문이 없으면 예외를 발생한다.
        - [ ] 현 주문상태가 **수락**이 아니면 예외를 발생한다.
     5. 배달 시작
        - [ ] 등록된 주문이 없으면 예외를 발생한다.
        - [ ] 주문 유형이 **배달**이 아니면 예외를 발생한다.
        - [ ] 현 주문상태가 **서빙/준비 완료**가 아니면 예외를 발생한다.
     6. 배달 완료
        - [ ] 등록된 주문이 없으면 예외를 발생한다.
        - [ ] 현 주문상태가 **배달중**이 아니면 예외를 발생한다.
     7. 주문 완료
        - [ ] 등록된 주문이 없으면 예외를 발생한다.
        - [ ] 배달(주문유형)인데 배달완료(주문상태)가 아니면 예외를 발생한다.
        - [ ] 포장, 먹고가기(주문유형)인데 서빙완료(주문상태)가 아니면 예외를 발생한다.
        - [ ] 먹고가기(주문유형)일 경우 테이블 주문 + 주문 모두 완료 처리한다.
   
****
### 6. 테이블 주문 (order table)
  - [x] 테이블 주문은 테이블번호, 인원수, 사용여부 값을 필수로 가진다.
  
  - API
     1. 테이블 주문 조회
        - [ ] 테이블 주문 조회시 특정 조건 없이 모든 목록을 조회할 수 있다.
        - [ ] 테이블 주문 조회시에 결과 수에 대한 제한이 필요하다.
     2. 테이블 주문 등록
        - [ ] 테이블 번호(테이블명)는 존재해야 한다.
     3. 테이블 착석
        - [ ] 등록된 테이블 주문이 없으면 예외를 발생한다.
        - [ ] 테이블 사용중 처리한다.
     4. 테이블 정리
        - [ ] 등록된 테이블 주문이 없으면 예외를 발생한다.
        - [ ] 테이블 주문이 있는데 주문상태가 **완료**가 아니면 예외를 발생한다.
        - [ ] 테이블 사용중지 처리한다.
     5. 테이블 인원 변경
        - [ ] 등록된 테이블 주문이 없으면 예외를 발생한다.
        - [ ] 테이블 사용중이 아니면 예외를 발생한다.
        - [ ] 테이블 인원수는 0이상 이어야 한다.

   
****
### 7. 주문 아이템 (order line item)
  - [x] 주문수량, 메뉴 key, 주문 key 값을 필수로 가진다.
  
  
****
## 용어 사전
### 주문 유형 (order type)
| 한글명 | 영문명 | 설명 |
|----|-----|----|
| 배달 | DELIVERY | 배달로 주문할 경우 |
| 포장 | TAKEOUT | 포장으로 주문할 경우 |
| 먹고가기 | EAT_IN  | 먹고가기(테이블 주문) 주문할 경우 |

  


### 주문 상태 (order status)
| 한글명   | 영문명 | 설명                     |
|-------| --- |------------------------|
| 대기    | WAITING | 주문 요청상태 (주문 등록 후 대기상태) |
| 수락    | ACCEPTED | 주문 요청 후 수락상태           |
| 서빙/제공 | SERVED | 주문 수락 후 서빙/제공완료 상태     |
| 배달    | DELIVERING | 서빙/제공완료 후 배달중 상태       |
| 배달완료  | DELIVERED | 배달중 이후 배달완료 상태         |
| 주문완료  | COMPLETED | 주문 완료 상태               |

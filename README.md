# 키친포스

## 요구사항
배달 & 테이블 주문이 가능한 식당의 포스기 기능을 구현한다. 

### 상품
- 상품을 생성할 수 있다.
- 상품을 생성할 때 아래의 정보가 필요하다.
  - 상품명, 상품 가격
  - 예시:
    - 상품명 : 후라이드
    - 상품 가격 : 16000
  - *상품명은 종교적이거나 비속어를 사용할 수 없다.*
- 상품의 가격을 수정할 수 있다.
  - *상품이 등록된 메뉴들에 대해서 메뉴의 가격이 메뉴 상품 목록의 가격 합보다 크면 상품 가격을 변경할 수 없다.*
- 상품 목록을 조회할 수 있다.
  - 상품이 없으면 빈 목록이 조회된다.

### 메뉴 그룹
- 메뉴 그룹을 생성할 수 있다.
- 메뉴 그룹을 생성할 때 다음의 정보가 필요하다
  - 메뉴 그룹 이름
    - 예시 : 신메뉴
- 메뉴 그룹 목록을 조회할 수 있다.
  - 메뉴 그룹이 없으면 빈 목록이 조회된다.

### 메뉴
- 메뉴를 생성할 수 있다
- 메뉴를 생성할 때 아래의 정보가 필요하다
  - 이름, 가격, 메뉴 그룹 ID, 노출 여부, 메뉴 상품 목록
  - 예시 : 
    - 이름 : 후라이드 치킨
    - 가격 : 16000
    - 메뉴 그룹 ID : f59b1e1c-b145-440a-aa6f-6095a0e2d63b
    - 노출 여부 : true
    - 메뉴 상품 목록
      - 예시 :
        1. 1번 메뉴 상품
          - 상품 ID : 3b528244-34f7-406b-bb7e-690912f66b10
          - 개수 : 1
        2. 2번 메뉴 상품
          - 상품 ID : 3b528244-34f7-406b-bb7e-690912f66b12
          - 개수 : 2
  - *메뉴의 가격이 메뉴 상품 목록의 가격 합보다 크면 생성할 수 없다.*
- 메뉴 가격을 수정할 수 있다.
  - *메뉴의 가격이 메뉴 상품 목록의 가격 합보다 크면 수정할 수 없다.*
- 메뉴를 숨길 수 있다.
- 메뉴를 노출할 수 있다.
  - *메뉴의 가격이 메뉴 상품 목록의 가격 합보다 크면 노출할 수 없다.*
- 메뉴 목록을 조회할 수 있다.
  - 메뉴가 없으면 빈 목록이 조회된다.

### 주문 테이블
- 주문 테이블을 생성할 수 있다.
- 주문 테이블을 생성할 때 아래의 정보가 필요하다.
  - 테이블 번호
    - 예시 : 1번
- 주문 테이블의 상태를 아래와 같이 수정할 수 있다.
  - 고객 착석
  - 테이블 청소 완료
- 주문 테이블에 고객 수를 수정할 수 있다.
- 주문 테이블 목록을 조회할 수 있다.
  - 주문 테이블이 없으면 빈 목록이 조회된다.

### 주문
- 주문을 생성할 수 있다.
- 주문은 아래의 타입으로 나뉜다.
  - 매장 식사 주문
  - 배달 주문
  - 포장 주문
- 매장 식사 주문
  - 매장 식사 주문을 생성할 때 아래의 정보가 필요하다.
    - 주문 타입, 주문 테이블 ID, 주문 상품 목록
    - 예시 : 
      - 주문 타입 : 매장 식사
      - 주문 테이블 ID : 8d710043-29b6-420e-8452-233f5a035520
      - 주문 상품 목록
        - 예시 : 
          1. 1번 주문 상품 :
            - 메뉴 id : f59b1e1c-b145-440a-aa6f-6095a0e2d63b
            - 가격 : 16000
            - 개수 : 1
          2. 2번 주문 상품 :
            - 메뉴 id : f59b1e1c-b145-440a-aa6f-6095a0e2d63c
            - 가격 : 14000
            - 개수 : 2
  - 매장 식사 주문의 상태를 아래와 같이 수정할 수 있다.
    - 주문 수락
    - 조리 완료
    - 주문 완료
- 배달 주문
  - 배달 주문을 생성할 때 아래의 정보가 필요하다.
    - 주문 타입, 배달 주소, 주문 상품 목록
    - 예시 : 
      - 주문 타입 : 배달
      - 배달 주소 : 서울시 송파구 위례성대로 2
      - 주문 상품 목록
        - 예시 : 
          1. 1번 주문 상품 :
             - 메뉴 id :f59b1e1c-b145-440a-aa6f-6095a0e2d63b
             - 가격 : 16000
             - 개수 : 1
          2. 2번 주문 상품 : 
             - 메뉴 id :f59b1e1c-b145-440a-aa6f-6095a0e2d63c
             - 가격 : 14000
             - 개수 : 2
  - 배달 주문의 상태를 아래와 같이 수정할 수 있다.
    - 주문 수락
    - 조리 완료
    - 배달 시작
    - 배달 완료
    - 주문 완료
- 포장 주문
  - 포장 주문을 생성할 때 아래의 정보가 필요하다.
    - 주문 타입, 주문 상품 목록
      - 예시 : 
        - 주문 타입 : 포장
        - 주문 상품 목록
          - 예시 : 
            1. 1번 주문 상품 :
               - 메뉴 id :f59b1e1c-b145-440a-aa6f-6095a0e2d63b
               - 가격 : 16000
               - 개수 : 1
            2. 2번 주문 상품 :
               - 메뉴 id :f59b1e1c-b145-440a-aa6f-6095a0e2d63c
               - 가격 : 14000
               - 개수 : 2
  - 포장 주문의 상태를 아래와 같이 수정할 수 있다.
    - 주문 수락
    - 조리 완료
    - 주문 완료
- 주문 목록을 조회할 수 있다.
  - 주문이 없으면 빈 목록이 조회된다.

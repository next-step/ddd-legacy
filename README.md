# 키친포스

## 퀵 스타트

```sh
cd docker
docker compose -p kitchenpos up -d
```

## 요구 사항

### 상품

- 각 상품은 고유 id가 있다
- 상품은 가격이 있다
    - 가격은 0 이상이어야 한다
- 상품 가격은 변경할 수 있다
    - 변경 시 해당 상품을 가지고있는 메뉴들의 가격도 변경된다
- 상품 리스트를 볼 수 있다

### 메뉴 그룹

- 각 메뉴 그룹은 고유 id가 있다
- 메뉴 그룹은 이름이 있다
    - 이름은 비어있을 수 없다
- 메뉴 그룹 리스트를 볼 수 있다

### 메뉴

- 각 메뉴는 고유 id가 있다
- 메뉴에는 이름이 있다
    - 욕설이 들어갈 수 없다
- 메뉴에는 가격이 있다
    - 가격은 음수일 수 없다
    - 메뉴에 속한 내역들의 합을 넘을 수 없다
        - 내역이란 메뉴에 속한 상품과 수량을 의미한다
- 메뉴는 하나의 메뉴 그룹에 속해야 한다
- 메뉴는 노출 여부를 선택해야한다
    - 노출 여부는 변경 가능하다
- 메뉴에는 여러 상품이 속할 수 있다
    - 최소 한 개 이상의 상품이 있어야한다
    - 각 상품은 0개 이상이어야한다
- 메뉴 리스트를 조회할 수 있다

### 주문

- 각 주문은 고유 id가 있다
- 주문은 하나의 주문 타입을 선택해야한다
    - 배달, 포장, 매장 식사 3가지 타입이 있다
- 주문은 주문 항목이 있어야한다
    - 주문 항목은 최소 한 개가 있어야 한다
    - 주문 항목은 여러 개일 수 있다
- 노출되지 않은 메뉴를 주문할 수 없다
- 주문은 대기(WAITING), 수락(ACCEPTED), 조리 완료(SERVED), 배달 중(DELIVERING), 주문 완료(COMPLETED) 6가지 상태가 있다
    - 최초 등록 시 대기 상태이다
- 주문 리스트를 볼 수 있다

### 주문>포장

- 주문 완료가 되려면 조리 완료 상태여야한다

### 주문>배달

- 주문 타입이 배달이어야만 배달을 시작할 수 있다
    - 배달 시작 시 주문 상태는 배달 중으로 변경된다
- 주문 상태가 조리 완료이면 배달을 시작할 수 없다
- 배달 완료는 이전 상태가 배달 중이어야 가능하다
- 주문 완료는 이전 상태가 배달 완료여야 가능하다

### 주문>매장 식사

- 매장 내에 주문 가능한 테이블을 주문 테이블이라고 부른다
- 주문 테이블은 고유 id가 있어야 한다
- 주문 테이블은 이름이 있어야한다
- 주문 테이블은 현재 고객 수를 알고 있어야한다
    - 최초 생성 시에는 0명이다
- 주문 테이블은 이용 상태를 가진다
    - 최초 등록 시 이용 가능 상태이다
- 주문 테이블을 이용 시 이용 중 상태로 바뀐다
- 주문 완료가 되려면 조리 완료 상태여야한다
- 매장 식사가 완료되면 해당 주문 테이블을 비운다
    - 주문 테이블을 이용 가능 상태로 변경한다
    - 주문 테이블 이용자 수를 0명으로 바꾼다

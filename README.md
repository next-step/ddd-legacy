# 키친포스

## 퀵 스타트

```sh
cd docker
docker compose -p kitchenpos up -d
```

## 요구 사항

- 간단한 키친포스를 구현한다.
- 상품
  - [ ] 상품을 등록 할 수 있다. 
    - [ ] 상품명이 필수 이다.
    - [ ] 상품명에는 비속어가 포함되면 안된다.
    - [ ] 가격은 0 이상이어야 한다.
  - [ ] 등록한 상품의 가격을 수정 할 수 있다. 가격은 0 이상이어야 한다. 상품이 속한 메뉴 가격이 상품의 총합보다 클 경우, 메뉴는 숨김 처리 한다.
  - [ ] 등록한 상품 목록을 조회 할 수 있다.
- 메뉴 그룹
  - [ ] 메뉴 그룹은 ID 와 이름을 가진다.
  - [ ] 메뉴 그룹을 등록 할 수 있다.
    - [ ] 메뉴 그룹 ID 는 자동 생성된다.
    - [ ] 이름은 필수 입력 이다.
  - [ ] 메뉴 그룹을 조회 할 수 있다.
  
- 메뉴
  - [ ] 메뉴를 등록 할 수 있다. 
    - [ ] 메뉴 이름은 필수이다.
    - [ ] 메뉴 이름에는 비속어가 포함되면 안된다.
    - [ ] 가격은 0 이상이어야 한다.
    - [ ] 메뉴는 하나의 메뉴 그룹에 속해야 한다. 
    - [ ] 메뉴는 1개 이상의 상품으로 구성되어야 한다. 
    - [ ] 메뉴 상품의 수량은 1개 이상이어야 한다.
    - [ ] 메뉴 가격은 메뉴 상품 가격의 총 합보다 작아야 한다. 
  - [ ] 메뉴의 가격을 수정할 수 있다. 
    - [ ] 메뉴 가격이 메뉴 상품 가격의 총 합보다 크다면 예외를 발생 시킨다.
  - [ ] 메뉴를 보이기 처리 할 수 있다. 
    - [ ] 메뉴 가격이 메뉴 상품 가격의 총 합보다 크다면 예외를 발생 시킨다.
  - [ ] 메뉴를 숨기기 처리 할 수 있다.
  - [ ] 전체 메뉴 목록을 조회 할 수 있다.
- 주문-테이블
  - [ ] 주문 테이블은 ID, 이름, 손님수, 점유여부를 속성으로 갖고 있다.
  - [ ] 주문 테이블을 등록 할 수 있다. 
    - [ ] 주문 테이블 이름은 필수 이다.  
  - [ ] 주문 테이블을 손님 앉음 상태로 수정 할 수 있다.
  - [ ] 주문 테이블을 사용 가능 상태로 수정 할 수 있다. 
    - [ ] 해당 주문-테이블의 주문상태가 완료가 아니면 예외를 발생 시킨다.
  - [ ] 주문 테이블에 손님 숫자를 수정 할 수 있다. 
    - [ ] 손님 숫자는 0 이상이어야 한다. 
    - [ ] 손님 앉음 상태가 아니면 예외를 발생 시킨다.
  - [ ] 주문 테이블 목록을 조회 할 수 있다.
- 주문
  - [ ] 주문은 ID, 주문 유형, 주문 상태, 주문 시각, 주문 항목, 배달 주소, 주문 테이블이 있다. 
  - [ ] 주문 유형에는 배달, 포장, 매장식사가 있다.
  - [ ] 주문 상태에는 대기, 수락, 제공, 배달 중, 배달 완료, 주문 완료 상태가 있다.
  - [ ] 주문을 접수 할 수 있다. 
    - [ ] 주문 유형은 필수다. 
    - [ ] 1개 이상 주문 항목이 있어야 한다. 
    - [ ] 매장 식사 외에는 각 주문 항목의 수량은 0 이상이어야 한다.
    - [ ] 주문 항목 중 선택한 메뉴가 숨김 상태일 경우 또는 메뉴 가격이 상품가격보다 클 경우 예외를 발생 시킨다.
    - [ ] 배달 주문의 경우 배달 주소는 필수 이다.
    - [ ] 매장식사 유형의 경우 주문-테이블 정보가 필수이다.
    - [ ] 매장식사 유형의 경우 요청 주문 테이블이 점유된 상태라면 예외를 발생 시킨다.
    - [ ] 주문을 접수하면 대기 상태가 된다.
  - [ ] 주문 수락 상태로 변경 할 수 있다. 
    - [ ] 주문 대기 중 상태가 아니면 예외를 발생 시킨다.
    - [ ] 주문 수락 시 배달 주문의 경우 주문 상품의 총 가격, 배달 주소 정보와 함께 배달 요청을 한다.
  - [ ] 주문 제공 상태로 변경 할 수 있다. 
    - [ ] 주문 수락 상태가 아니면 예외를 발생 시킨다.
  - [ ] 배달을 시작 할 수 있다.
    - [ ] 배달 시작 시 배달 중 상태로 변경 한다.
    - [ ] 배달 유형이 아닌 경우 예외를 발생 시킨다. 
    - [ ] 주문 제공 상태가 아니면 예외를 발생 시킨다.
  - [ ] 배달 완료 상태로 변경 할 수 있다. 
    - [ ] 배달 중 상태가 아닌 경우 예외를 발생 시킨다.
  - [ ] 주문은 완료 상태로 변경 할 수 있다. 
    - [ ] 배달 유형의 경우 배달 완료 상태가 아니면 예외를 발생 시킨다. 
    - [ ] 그외 유형은 제공 상태가 아니면 예외를 발생시킨다.
    - [ ] 매장식사 유형의 경우 주문 테이블이 완료 상태가 아닌 경우가 없으면 주문 테이블도 초기화 한다.

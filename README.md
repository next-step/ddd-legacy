# 키친포스

## 퀵 스타트

```sh
cd docker
docker compose -p kitchenpos up -d
```

## 요구 사항

- 식당에서 사용하는 메뉴와 제품 및 주문 시스템을 개발한다
- 메뉴 그룹
  - [ ] 메뉴의 종류를 메뉴 그룹(MenuGroup)이라고 부른다
  - [ ] 메뉴 그룹을 생성할 수 있다
  - [ ] 메뉴 그룹을 전체 조회할 수 있다
  - [ ] 메뉴 그룹은 수정하거나 삭제할 수 없다
- 제품
    - [ ] 제품을 생성할 수 있다
    - [ ] 제품을 전체 조회할 수 있다
    - [ ] 제품의 가격을 변경할 수 있다
- 메뉴
  - [ ] 메뉴를 생성할 수 있다
    - [ ] 메뉴는 메뉴 그룹 하나에 대응하고, 메뉴 그룹에는 여러 개의 메뉴가 포함된다
    - [ ] 메뉴는 여러 제품과 대응하고 제품의 재고를 관리한다
  - [ ] 메뉴를 전체 조회할 수 있다
  - [ ] 메뉴의 가격을 변경할 수 있다
  - [ ] 메뉴를 표시하거나 숨길 수 있다
- 주문 테이블
  - [ ] 식당에서 주문을 받을 수 있는 테이블을 주문 테이블이라고 부른다
  - [ ] 주문 테이블을 생성할 수 있다
    - [ ] 주문 테이블은 이름과 테이블 사용여부, 손님의 수를 정할 수 있다
  - [ ] 주문 테이블을 전체 조회할 수 있다 
  - [ ] 손님은 주문 테이블을 차지할 수 있다
  - [ ] 주문 테이블을 정리할 수 있다
    - [ ] 손님이 식사중일경우에는 테이블을 정리할 수 없다
  - [ ] 주문 테이블의 손님 수를 변경할 수 있다
    - [ ] 주문 테이블에 손님이 없으면 변경할 수 없다
- 주문
  - [ ] 주문의 종류는 배달, 포장, 매장 내 식사로 구분된다 
  - [ ] 식당은 주문을 받을 수 있다
    - [ ] 배달일경우 주소를 확인할 수 있어야 한다
    - [ ] 매장 내 식사일경우 비어있는 주문 테이블에서 식사할 수 있다
    - [ ] 여러 메뉴를 골라서 같이 주문할 수 있다
  - [ ] 주문을 전체 조회할 수 있다 
  - [ ] 주문의 상태는 주문 대기(WAITING), 확인(ACCEPTED), 서빙(SERVED), 배달 중(DELIVERING), 배달 완료(DELIVERED), 완료 상태(COMPLETED)의 상태를 가진다
    - [ ] 주문은 주문 대기중일 때만 확인할 수 있다
    - [ ] 확인된 주문은 요리가 모두 준비되면 서빙한다
    - [ ] 배달 주문일경우 음식이 모두 준비되어서 서빙되면 라이더에게 배달을 요청할 수 있다
    - [ ] 라이더가 배달을 완료하면 라이더는 배달 완료로 식당에 표시한다
    - [ ] 배달 주문은 배달이 완료되면 주문이 완료된다
    - [ ] 포장일경우 서빙이 완료되면 주문이 완료된다
    - [ ] 매장 내 식사일경우 주문 테이블을 정리하고 주문을 완료한다

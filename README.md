# 키친포스

## 퀵 스타트

```sh
cd docker
docker compose -p kitchenpos up -d
```

## 요구 사항
### 1. 상품 관리
#### 1.1 상품 등록
- 상품을 등록할 수 있다.
  - 상품은 상품 이름을 가져야 한다.
  - 상품은 상품 가격을 가져야 한다.
  - 상품의 가격은 0 이상이어야 한다.
  - 상품의 이름은 입력하지 않거나, 부적절한 표현을 포함할 수 없다.
#### 1.2 상품 수정
- 상품의 가격을 수정할 수 있다.
  - 수정된 상품의 가격은 0 이상이어야 한다.
  - 상품 가격 수정 시 해당 상품을 포함하는 메뉴들에 수정된 상품 가격이 반영되어야 한다.
  - 상품 가격 수정 시 메뉴의 가격이 메뉴 구성 상품 가격과 수량의 합보다 큰 경우 해당 메뉴를 표출할 수 없다.
#### 1.3 상품 조회
- 모든 상품을 조회할 수 있다.
- 등록되지 않은 상품은 조회할 수 없다.
---
### 2. 메뉴 관리
#### 2.1 메뉴 생성
- 메뉴를 생성할 수 있다.
  - 메뉴는 메뉴 이름을 가져야 한다.
  - 메뉴는 메뉴 가격을 가져야 한다.
  - 메뉴는 메뉴 표출 여부를 가져야 한다.
  - 메뉴의 가격은 0 이상이어야 한다.
  - 기존에 등록되어 있는 메뉴 그룹에만 등록할 수 있다.
  - 메뉴는 1개 이상의 메뉴 구성 상품을 가져야 한다.
  - 메뉴에 포함될 메뉴 구성 상품의 수량은 0 이상이어야 한다.
  - 기존에 등록된 상품만 메뉴에 포함될 수 있다.
  - 메뉴의 가격은 메뉴 구성 상품 가격과 수량의 합보다 클 수 없다.
  - 메뉴의 이름은 입력하지 않거나, 부적절한 표현을 포함할 수 없다.
#### 2.2 메뉴 수정
- 메뉴의 가격을 수정할 수 있다.
  - 메뉴의 가격 수정 시 메뉴의 가격이 메뉴 구성 상품 가격과 수량의 합보다 큰 경우 해당 메뉴를 표출할 수 없다.
#### 2.3 메뉴 표출
- 메뉴를 표출할 수 있다.
- 메뉴를 표출하지 않을 수 있다.
#### 2.4 메뉴 조회
- 모든 메뉴를 조회할 수 있다.
- 등록되지 않은 메뉴는 조회할 수 없다.
---
### 3. 메뉴 그룹 관리
#### 3.1 메뉴 그룹 등록
- 메뉴 그룹을 등록할 수 있다.
  - 메뉴 그룹은 메뉴 그룹 이름을 가져야 한다.
  - 메뉴 그룹의 이름은 비어있을 수 없다.
#### 3.2 메뉴 그룹 조회
- 모든 메뉴 그룹을 조회할 수 있다.
---
### 4. 주문 관리
#### 4.1 주문 등록
- 주문을 등록할 수 있다.
  - 주문은 배달 주문, 포장 주문, 매장 주문 타입을 가져야 한다. 
  - 주문은 주문 시각을 가져야 한다.
  - 주문은 1개 이상의 주문 항목을 가져야 한다.
  - 하나의 주문에서 주문 항목의 수와 주문 항목이 포함하는 메뉴의 수는 일치해야 한다.
  - 기존에 등록된 메뉴만 주문 항목에 포함될 수 있다.
  - 주문 항목은 표출 중인 메뉴만 포함할 수 있다.
  - 주문 항목의 가격과 주문 항목이 포함하는 메뉴의 가격은 일치해야 한다.
#### 4.2 주문 상태 변경
- 주문이 주문 대기 상태일 때만 주문 확인 상태로 변경할 수 있다.
- 주문이 주문 확인 상태일 때만 주문 준비 완료 상태로 변경할 수 있다.
- 주문이 주문 준비 완료 상태일 때만 주문 완료 상태로 변경할 수 있다. (단, 배달 주문은 제외)
#### 4.3 주문 조회
- 모든 주문을 조회할 수 있다.
- 등록되지 않은 주문은 조회할 수 없다.
---
### 5. 매장 주문 관리
### 5.1 매장 주문 등록
- 매장 주문을 등록할 수 있다.
  - 매장 주문은 기존에 등록된 주문 테이블에만 할당할 수 있다.
  - 사용 중이지 않은 주문 테이블에는 주문을 등록할 수 없다.
### 5.2 매장 주문 완료 처리
- 매장 주문 완료 시 주문 테이블을 초기화한다.
  - 주문 테이블의 손님 수를 0으로 수정한다.
  - 주문 테이블의 사용 중 여부를 '사용 중이지 않음'으로 변경한다.
### 5.3 매장 주문 상태 흐름
- 대기(Waiting) → 주문 확인(Accepted) → 준비 완료(Served) → 완료(Completed)
---
### 6. 포장 주문 관리
#### 6.1 포장 주문 등록
- 포장 주문을 등록할 수 있다.
  - 주문 항목의 수량은 0 이상이어야 한다.
#### 6.2 포장 주문 상태 흐름
- 대기(Waiting) → 주문 확인(Accepted) → 준비 완료(Served) → 완료(Completed)
---
### 7. 배달 주문 관리
#### 7.1 배달 주문 등록
- 배달 주문을 등록할 수 있다.
  - 주문 항목의 수량은 0 이상이어야 한다.
  - 배달 주소를 입력해야 하며, 배달 주소는 비어있을 수 없다.
#### 7.2 배달 진행 관리
- 주문 확인 시점에 배달 요청을 외부시스템으로 전송한다.
- 주문이 주문 준비 완료 상태에서만 배달 중 상태로 변경할 수 있다.
- 주문이 배달 중 상태일 때만 주문 배달 완료 상태로 변경할 수 있다.
- 주문이 주문 배달 완료 상태일 때만 주문 완료 상태로 변경할 수 있다.
#### 7.3 배달 주문 상태 흐름
- 대기(Waiting) → 주문 확인(Accepted) → 준비 완료(Served) → 배달 중(Delivering) → 배달 완료(Delivered) → 완료(Completed)
---
### 8. 주문 테이블 관리
#### 8.1 주문 테이블 등록
- 주문 테이블을 등록할 수 있다.
  - 주문 테이블은 테이블 이름을 가져야 한다.
  - 주문 테이블의 이름은 비어있을 수 없다.
  - 주문 테이블은 손님 수를 가져야 한다.
  - 주문 테이블의 손님 수는 0 이상이어야 한다.
  - 주문 테이블은 사용 중 여부를 가져야 한다.
#### 8.2 주문 테이블 상태 변경
- 주문 테이블의 사용 중 여부를 변경할 수 있다.
- 주문 테이블을 초기화할 수 있다.
  - 초기화 시 주문 테이블의 손님 수를 0으로 수정한다.
  - 초기화 시 주문 테이블의 사용 중 여부를 '사용 중이지 않음'으로 수정한다.
- 주문 테이블을 비울 수 있다.
  - 주문 테이블을 비우기 위해서는 해당 테이블의 모든 주문이 주문 완료 상태여야 한다.
#### 8.3 주문 테이블 수정
- 주문 테이블의 손님 수를 수정할 수 있다.
  - 수정된 손님 수는 0 이상이어야 한다.
  - 손님 수를 수정하려면 해당 주문 테이블이 사용 중 상태여야 한다.
#### 8.4 주문 테이블 조회
- 모든 주문 테이블을 조회할 수 있다.
- 등록되지 않은 주문 테이블은 조회할 수 없다.

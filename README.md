# 키친포스

## 퀵 스타트

```sh
cd docker
docker compose -p kitchenpos up -d
```

## 요구 사항
- 상품과 메뉴를 등록하고 주문하는 키친포스 시스템을 구현합니다.

### 주문 상태 순서도

![img.png](https://github.com/user-attachments/assets/8b6c38db-928c-4bdc-ae6b-10f6f88a8ee3)

### 상품
> 상품이란 판매될 수 있는 물건이나 음식등을 의미합니다.
> 
> 여기서는 음식이 상품이 될 수 있을 것입니다. (치킨, 피자 등등)
- 
- [x] 상품 등록 기능 - 상품 가격과 상품명을 입력하여 등록합니다.
  - [x] 상품명이 없거나 비속어가 있으면 안됩니다.
  - [x] 가격은 0원 이상이어야 합니다. 
- [x] 가격 변경 기능 - 상품의 가격을 변경할 수 있습니다.
  - 등록되어 있는 상품의 id와 변경할 상품 정보(상품명, 가격, id)를 입력받습니다.
  - 상품 id는 등록되어 있는 상품이어야 합니다.
  - [x] 변경할 상품의 가격은 0원 이상이어야 합니다.
  - [x] 메뉴의 가격이 메뉴의 상품들(동일 상품일수도 있고, 다른 상품일 수도 있습니다.) 
  의 총 가격 합보다 크면, 화면에서 비노출합니다.
- [ ] 모든 상품을 조회할 수 있습니다.


### 메뉴
> 메뉴란 음식점에서 실제로 소비자에게 제안되는 상품들을 목록화한 것입니다. 
>
> 상품개별이 될 수도, 여럿이 될 수도 있습니다.
> 
> ex : 치킨 + 콜라, 치킨 + 피자
> 
> 주문 상품은 상품, 상품의 수량을 포함하는 개념입니다.

- [ ] 메뉴 등록 기능
  - 주문상품 하나당 1개의 상품만 등록할 수 있습니다.
  - 등록하려는 메뉴의 주문상품들 총 갯수와 주문상품들 각각을 구성하는 상품들의 총갯수는 같아야 합니다.
  - 메뉴는 단일 이거나 동일, 별개의 상품들을 조합해서 만들 수 있습니다.
  - 메뉴는 상품과 그 상품의 수량을 선택할 수 있습니다.
  - 주문상품을 구성하는 상품은 등록되어 있는 상품이어야 합니다.
  - [x] 메뉴의 가격은 0원 이상이어야 합니다.
  - [x] 메뉴의 주문 상품이 1개 이상 존재해야 합니다.
  - [x] 메뉴 내부 상품의 수량은 0개 이상이어야 합니다.
  - [ ] 등록하려는 메뉴의 가격이 메뉴에 포함된 상품의 총 가격보다 높으면 안됩니다.
  - [ ] 메뉴의 이름이 없거나 비속어가 들어가 있으면 안됩니다.

- [ ] 메뉴 가격 수정 기능
  - [ ] 수정 메뉴의 가격은 0원 이상이어야 합니다
  - [ ] 수정 하려는 메뉴는 이미 등록이 되어 있는 메뉴여야 합니다.
  - [ ] 메뉴에 포함된 상품들의 가격 합보다 수정하려는 금액이 크면 안됩니다.

- [ ] 메뉴 노출 기능
  - [ ] 노출 요청하는 메뉴가 이미 등록되어 있는 메뉴여야 합니다
  - [ ] 메뉴내 포함된 금액의 합이 메뉴 금액보다 커서는 안됩니다
  - [ ] 메뉴 노출을 활성화 시킵니다.
- [ ] 메뉴 비노출 기능
  - [ ] 비노출하려는 메뉴는 이미 존재하는 메뉴여야 합니다.
  - [ ] 메뉴를 비노출합니다.
- [ ] 모든 메뉴 찾기 기능
  - [ ] 등록되어 있는 모든 메뉴를 조회합니다.

### 메뉴 그룹
> 메뉴그룹이란 공통적인 메뉴들을 묶어놓은 것입니다.
>
> ex : 두마리 메뉴 : 후라이드 + 후라이드


- [ ] 메뉴 그룹 등록 기능
  - [ ] 메뉴그룹의 이름이 없으면 안됩니다.
  - [ ] 메뉴그룹의 id는 랜덤으로 생성해서 저장합니다.
- [ ] 모든 메뉴그룹 조회 기능

### 주문
> 주문이란 사용자가 메뉴를 선택하여 제공받는 것입니다.
> 메뉴에 맞는 값 지불이 필요합니다.
> 
> 주문상품이란, 주문한 메뉴, 수량, 가격을 합쳐서 나타낸 뜻입니다.

- [ ] 주문 추가 기능
  - [ ] 주문 타입은 매장내 식사 or 배달 중 하나를 반드시 선택해야 합니다.
  - [ ] 주문상품은 최소한 1개 이상의 메뉴를 선택해야 합니다.
  - [ ] 주문한 메뉴는 등록되어 있어야 합니다.
  - [ ] 배달이거나 포장주문일 경우, 주문상품의 수량은 0개 이상이어야 합니다.
  - [ ] 선택된 메뉴가 비노출되어 있는 상태면 안됩니다.
  - [ ] 선택된 메뉴의 금액과 주문요청한 메뉴의 금액은 같아야 합니다.
  - [ ] 주문 검증이 끝나면 주문대기(WAITING) 상태가 됩니다.
  - [ ] 배달주문인 경우, 반드시 배달 주소를 입력하여 배달기사에게 전달합니다.
  - [ ] 매장내 식사일 경우, 배정요청한 주문 테이블이 사용가능이어야 합니다.
- [ ] 주문 접수 기능
  - [ ] 주문이 등록되어 있고 상태가 주문대기(WAITING)이어야 합니다.
  - [ ] 주문정보(주문상품들의 총액과 배달 주소)를 제공합니다.
  - [ ] 주문의 상태를 주문 수락(ACCEPTED)로 변경합니다.
- [ ] 주문 수락 상태의 주문을 제공하는 기능.
  - [ ] 요청된 주문은 주문 수락상태(ACCEPTED)로 존재하는 주문이어야 합니다.
  - [ ] 상태를 제공완료(SERVED)로 변경합니다.
- [ ] 배달 주문의 경우 배달을 시작합니다.
 - [ ] 타입이 매장내 식사가 아닌 배달이어야 합니다.
 - [ ] 상태가 제공완료(SERVED)상태가 되면 안됩니다.
 - [ ] 상태를 배달중(DELIVERING)으로 변경합니다.
- [ ] 배달 완료 기능.
  - [ ] 요청된 주문은 상태가 배달중(DELIVERING)인 상태로 존재해야 합니다.
  - [ ] 상태를 배달 완료(DELIVERED)으로 변경합니다.
- [ ] 주문 완료 기능.
  - [ ] 등록 되어있는 주문이어야 합니다.
  - [ ] 배달인 주문일 경우 상태가 배달 완료(DELIVERED)가 아니면 안됩니다.
  - [ ] 포장이나 매장내 식사 주문일 경우 상태가 제공완료(SERVED)이어야 합니다.
  - [ ] 매장내 식사일 경우, 제공된 주문 테이블 상태가 전부 제공완료 상태이면 테이블을 정리합니다.
    - [ ] 인원을 0명으로 변경합니다.
    - [ ] 테이블 상태를 사용가능으로 변경합니다.
  - [ ] 상태를 주문완료(COMPLETED)로 변경합니다.
- [ ] 모든 주문 확인 기능

### 주문 테이블
> 주문 테이블이란 매장내 식사를 하는 인원들에게 배정되어야 하는 것입니다.
>
- [ ] 주문 테이블 등록 기능
  - [ ] 이름은 비어있으면 안됩니다.
  - [ ] 최초 등록시 첫인원은 0명으로 등록합니다.
  - [ ] 최초 등록시 테이블 사용 가능으로 등록합니다.
- [ ] 주문 테이블에 손님 배정 기능
  - [ ] 배정하려는 주문테이블이 존재해야 합니다.
  - [ ] 배정된 테이블을 사용중으로 변경합니다.
- [ ] 주문 테이블 정리기능
  - [ ] 정리하려는 테이블이 존재해야 합니다.
  - [ ] 테이블의 주문 상태가 주문완료(COMPLETED)여야 합니다.
  - [ ] 인원을 0명으로 변경합니다.
  - [ ] 테이블 상태를 사용가능으로 변경합니다.
- [ ] 테이블 인원 변경 기능
  - [ ] 인원의 수는 음수가 되면 안됩니다.
  - [ ] 인원을 변경하려는 테이블이 존재해야 합니다.
  - [ ] 테이블이 사용가능 상태이면 안됩니다.
  - [ ] 전달받은 인원 수로 테이블 인원을 변경합니다.
- [ ] 모든 주문 테이블 조회 기능

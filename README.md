# 키친포스

## 퀵 스타트

```sh
cd docker
docker compose -p kitchenpos up -d
```

## 요구 사항

### 상품 관리
- [ ] 상품을 등록할 수 있다.
  - 상품명과 가격 정보가 포함되어야 한다.
  - 가격은 0원 이상의 양수만 허용한다.
  - 가격은 100원 단위로 설정 가능하다.
  - 최대 가격은 1,000,000원으로 제한한다.
- [ ] 상품 목록을 조회할 수 있다.

### 메뉴 그룹 관리
- [ ] 메뉴 그룹을 등록할 수 있다.
  - 메뉴 그룹명이 포함되어야 한다.
- [ ] 메뉴 그룹 목록을 조회할 수 있다.

### 메뉴 관리
- [ ] 메뉴를 등록할 수 있다.
  - 메뉴명, 가격, 메뉴 그룹, 출력 여부가 포함되어야 한다.
  - 메뉴에 포함되는 상품 정보를 입력할 수 있다.
- [ ] 메뉴 가격을 변경할 수 있다.
- [ ] 메뉴를 숨기거나 보이게 할 수 있다.
  - 메뉴 숨김 조건:
    - 재료 소진으로 인한 일시 품절
    - 계절 메뉴의 판매 기간 종료
    - 판매 중단된 메뉴
  - 숨김 처리된 메뉴는 주문 불가능하다.
  - 숨김 처리된 메뉴도 과거 판매 이력은 유지한다.
- [ ] 메뉴 목록을 조회할 수 있다.

### 주문 테이블 관리
- [ ] 주문 테이블을 등록할 수 있다.
  - 테이블 이름과 손님 수가 포함되어야 한다.
- [ ] 주문 테이블의 손님 수를 변경할 수 있다.
- [ ] 주문 테이블의 사용 여부를 변경할 수 있다.
  - 테이블이 비어있는지, 사용 중인지 설정할 수 있다.
- [ ] 주문 테이블 목록을 조회할 수 있다.

### 주문 관리
- [ ] 주문을 등록할 수 있다.
  - 주문 유형(매장/포장)을 지정할 수 있다.
  - 주문 테이블 정보가 포함되어야 한다.
  - 주문 항목(메뉴, 수량)을 입력할 수 있다.
- [ ] 주문의 상태를 변경할 수 있다.
  - 주문 수락
  - 요리 완료
  - 배달 시작 (배달 주문의 경우)
  - 배달 완료 (배달 주문의 경우)
  - 주문 완료
- [ ] 주문 목록을 조회할 수 있다.

- 주문 상태는 다음과 같이 정의한다:
  - `WAITING`: 주문이 접수되어 대기 중인 상태
  - `COOKING`: 주문한 음식이 조리 중인 상태
  - `SERVED`: 음식이 고객에게 제공된 상태
  - `COMPLETED`: 결제가 완료된 상태
  - `CANCELED`: 주문이 취소된 상태

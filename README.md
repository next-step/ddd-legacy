# 도메인 주도 설계 이해

## STEP 2 - Kitchen pos 요구사항

### 요구 사항

키친POS는 레스토랑의 주문과 메뉴를 관리하는 시스템입니다.

## 요구사항

### 메뉴
- 메뉴를 등록한다.
  - [ ] 메뉴 가격은 0원 이상이어야 한다.
  - [ ] 메뉴는 메뉴 그룹에 속해야 한다.
  - [ ] 메뉴는 1개 이상의 상품으로 구성된다.
  - [ ] 메뉴 생성 시 지정된 모든 상품이 실제로 데이터베이스에 존재해야 한다.
  - [ ] 메뉴 상품 수량은 0개 이상이어야 한다.
  - [ ] 메뉴 가격의 합이 구성 상품의 가격 총합보다 큰 경우 등록할 수 없다.
  - [ ] 메뉴 이름에는 비속어가 포함될 수 없다 (profanity).
- 메뉴를 수정한다.
  - 메뉴 가격을 변경할 수 있다
    - [ ] 메뉴 가격은 0원 이상이어야 한다
    - [ ] 메뉴 가격의 합이 구성 상품의 가격 총합보다 큰 경우 수정할 수 없다.
  - 메뉴 디스플레이 상태 변경
    - [ ] 메뉴를 전시(display) 상태로 변경할 수 있다.
      - 메뉴의 실제 가격이 구성 상품들의 총 가격보다 크면 전시할 수 없다
      - 메뉴의 실제 가격이 구성 상품들의 총 가격보다 작거나 같으면 전시할 수 있다 
    - [ ] 메뉴를 숨김(hide) 상태로 변경할 수 있다.
      - 메뉴가 존재 하지 않는 경우 숨김 상태로 변경할 수 없다
- 메뉴를 조회한다.
  - [ ] 메뉴를 조회할 수 있다
### 메뉴 그룹
- 메뉴 그룹을 등록한다.
  - [ ] 메뉴 그룹 이름은 필수이다.
-  메뉴 그룹을 조회한다.
  - [ ] 메뉴 그룹을 조회할 수 있다

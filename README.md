# 키친포스

## 퀵 스타트

```sh
cd docker
docker compose -p kitchenpos up -d
```

## 요구 사항

> 식당 관리를 돕는 키친포스 시스템을 개발한다
- 메뉴 그룹
  > 메뉴의 종류를 메뉴 그룹(MenuGroup)이라고 부른다<br/>MenuGroup: 한마리메뉴, Menu: 후라이드치킨<br/>MenuGroup: 사이드메뉴, Menu: 치즈볼
  - [ ] 메뉴 그룹을 생성할 수 있다
    - [ ] 메뉴 그룹의 이름을 반드시 지정해야 한다 
  - [ ] 메뉴 그룹을 전체 조회할 수 있다
<br/><br/>
- 상품
    - [ ] 상품을 생성할 수 있다
      - [ ] 상품의 가격은 0원 이상이어야 한다
      - [ ] 상품의 이름을 반드시 지정해야 한다
      - [ ] 상품의 이름에는 욕설이 포함되어서는 안된다
    - [ ] 상품을 전체 조회할 수 있다
    - [ ] 상품의 가격을 변경할 수 있다
      - [ ] 상품이 존재해야 한다 
      - [ ] 상품의 가격은 0원 이상이어야 한다
      - [ ] 상품을 사용하는 메뉴의 가격이 메뉴를 구성하는 상품 가격의 총 합보다 클 경우 메뉴를 숨긴다
<br/><br/>
- 메뉴
  - [ ] 메뉴를 생성할 수 있다
    - [ ] 메뉴의 이름을 반드시 지정해야 한다
    - [ ] 메뉴의 이름에는 욕설이 포함되어서는 안된다
    - [ ] 메뉴는 메뉴 그룹을 지정해야 한다
    - [ ] 메뉴의 노출 여부를 지정할 수 있다
    - [ ] 메뉴는 하나 이상의 상품을 사용해야 한다
    - [ ] 메뉴의 가격은 0원 이상이어야 한다
    - [ ] 메뉴의 가격은 상품 가격의 총합보다 클 수 없다
  - [ ] 메뉴를 전체 조회할 수 있다
  - [ ] 메뉴의 가격을 변경할 수 있다
    - [ ] 메뉴의 가격은 0원 이상이어야 한다
    - [ ] 메뉴의 가격은 상품 가격의 합보다 클 수 없다
  - [ ] 메뉴를 표시하게 변경할 수 있다
    - [ ] 메뉴의 가격이 상품 가격의 합보다 클 경우에는 화면에 표시할 수 없다 
  - [ ] 메뉴를 숨기게 변경할 수 있다
<br/><br/>
- 주문 테이블
  > 식당에서 주문을 받을 수 있는 테이블을 주문 테이블이라고 부른다
  - [ ] 주문 테이블을 생성할 수 있다
    - [ ] 주문 테이블의 이름을 반드시 지정해야 한다
  - [ ] 주문 테이블을 전체 조회할 수 있다
  - [ ] 손님은 주문 테이블에 착석할 수 있다
  - [ ] 주문 테이블을 정리할 수 있다
    - [ ] 주문이 완료되지 않았을경우 테이블을 정리할 수 없다
  - [ ] 주문 테이블의 손님 수를 변경할 수 있다
    - [ ] 손님 수는 0명 이상이어야 한다
    - [ ] 주문 테이블에 손님이 없으면 변경할 수 없다
<br/><br/>
- 주문
  - [ ] 주문의 종류는 배달, 포장, 매장 내 식사로 구분된다 
  - [ ] 식당은 주문을 받을 수 있다
    - [ ] 주문의 종류를 반드시 지정해야 한다
    - [ ] 식당에 없는 메뉴는 주문할 수 없다
    - [ ] 여러 메뉴를 골라서 같이 주문할 수 있다
    - [ ] 메뉴의 가격과 주문한 메뉴의 가격이 동일해야 한다
    - [ ] 배달일경우 배달 주소를 확인할 수 있어야 한다
    - [ ] 매장 내 식사가 아니라면 음식의 갯수는 0 이상이어야 한다
    - [ ] 매장 내 식사일경우 비어있는 주문 테이블에서만 식사할 수 있다
  - [ ] 주문을 전체 조회할 수 있다 
  - [ ] 주문의 상태는 주문 대기(WAITING), 수락(ACCEPTED), 서빙(SERVED), 배달 중(DELIVERING), 배달 완료(DELIVERED), 완료 상태(COMPLETED)의 상태를 가진다
    - [ ] 주문 대기 상태의 주문만 수락할 수 있다
      - [ ] 배달 주문일경우 주문이 수락되면 배달 서비스에 배달을 요청한다 
    - [ ] 수락된 주문은 요리가 모두 준비되면 서빙한다
    - [ ] 배달 주문일경우 음식이 모두 준비되어서 서빙되면 라이더가 배달을 시작한다
    - [ ] 라이더가 배달을 완료하면 라이더는 배달 완료로 식당에 표시한다
    - [ ] 주문 과정이 모두 끝나면 주문을 완료할 수 있다
      - [ ] 배달 주문은 배달 완료 상태의 주문만 주문을 완료할 수 있다
      - [ ] 매장 내 식사나 포장일경우 서빙된 상태의 주문만 주문을 완료할 수 있다
      - [ ] 매장 내 식사일경우 주문을 완료할 수 있고, 주문이 완료 상태가 아니었다면 주문 테이블을 정리한다.

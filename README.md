## 요구 사항
- 식당에서 음식 주문을 받는 서비스를 구연한다.

- 메뉴(Menu) : 현재 판매될수 있는 상품의 묶음
  - [ ] 메뉴는 생성/조회 가능하다.
    - [ ] 각 메뉴는 1개의 메뉴 그룹을 필수로 갖는다.
    - [ ] 각 메뉴는 1개 이상의 메뉴 상품을 필수로 가져야 하며, 해당 메뉴 상품들은 모두 등록된 상품이어야 한다.
    - [ ] 각 메뉴는 유니크한 ID를 갖는다. (UUID)
    - [ ] 가격(price) 은 필수로 입력되어야 하며, 0 이상의 양수값 이어야 한다.
    - [ ] 메뉴의 이름(name)은 필수로 입력되어야 하며, 비속어가 포함될 수 없다.
  - [ ] 메뉴 가격 변경이 가능하다.
    - [ ] 변경되는 가격은 0 이상의 양수값 이어야 한다. 
    - [ ] 가격은 변경이 가능하나, 포함한 메뉴 상품의 가격의 합보다 클수 없다.
  - [ ] 메뉴 화면 표시 여부 변경이 가능하다.
    - [ ] 단, 메뉴의 가격이 상품의 가격합 보다 큰 경우 변경 할 수 없다.
  
- 메뉴 그룹 (MenuGroup) : 판매되는 메뉴의 상위 분류값
  - [ ] 메뉴 그룹은 생성/조회가 가능하다.
  - [ ] 각 메뉴 그룹은 유니크한 ID를 갖는다. (UUID)
  - [ ] 이름은 필수로 입력되어야 한다.
  
- 상품(Product) : 판매되는 상품
  - [ ] 상품은 조회가 가능하다.  
    - [ ] 조회시 모든 상품을 나타낸다.
  - [ ] 상품은 생성이 가능하다.
    - [ ] 상품 생성시 가겨은 필수로 입력되어야 하며, 0 이상의 양수값만 가능하다.
    - [ ] 상품의 이름은 필수로 입력되어야 하며, 비속어가 포함될 수 없다.
  - [ ] 상품의 가격은 변동 가능하다.
    - [ ] 변경되는 가격은 필수로 입력되어야 하며, 0 이상의 양수값만 가능하다.
    - [ ] 변경후 메뉴의 가격 보다 메뉴 상품 총 가격값이 크다면 해당 메뉴를 비활성화 한다.

- 주문 (Order) : 사용자가 주문한 상품 목록
  - [ ] 주문은 총 6가지의 상태가 존재한다. 
    - 준비(WAITTING), 수락(ACCEPTED), 서빙됨(SERVED), 배달중(DELIVERING), 배달완료(DELIVERD), 완료(COMPLETED)
  - [ ] 주문은 생성이 가능하다.
    - [ ] 주문은 총 3가지의 타입이 존재한다. ( 배달(DELIVERY), 포장(TAKEOUT), 매장식사(EAT_IN)) 
    - [ ] 주문의 타입은 필수로 입력되어야 한다.
      - [ ] 주문 타입이 매장식사(EAT_IN) 일때
        - [ ] 주문 내역의 수량은 필수값이다.
        - [ ] 사용 가능한 식사 테이블이 있어야 한다.
        - [ ] 위 조건 만족시, 식사 테이블을 할당한다.
      - [ ] 주문 타입이 배달(DELIVERY) 일때
        - [ ] 배송지 주소는 필수값이다.
        - [ ] 위 조건 만족시, 배송지를 설정한다.
    - [ ] 주문 내역은 필수이다. 해당 주문 내역들은 메뉴에 포함되어있는 항목이어야 한다.
    - [ ] 주문 내역 중 활성화 되지 않은 메뉴는 포함될수 없다.
    - [ ] 주문내역 가격과 메뉴의 가격이 다르면 주문할 수 없다.
    - [ ] 주문 생성시 상태는 준비(WAITTING) 상태로 생성된다.
    - [ ] 주문 시간은 검증이 끝난 후 시간으로 설정한다.
  - [ ] 주문의 상태는 변경이 가능하다.
    - [ ] 주문은 '수락(ACCEPTED)' 상태로 변경이 가능하다.
      - [ ] 주문의 상태가 준비(WAITTING) 인 경우에만 수락이 가능하다.
      - [ ] 주문 타입이 배달(DELIVERY) 인경우
        - [ ] 배달 라이더 클라이언트 요청을 진행한다.
        - [ ] 배달지 주소와 총 가격을 배달부에게 전달한다.
    - [ ] 주문은 '서빙됨(SERVED)' 상태로 변경이 가능하다.
      - [ ] 주문의 상태가 수락(ACCEPTED) 인 경우에만 서빙이 가능하다.
    - [ ] 주문은 '배달중(DELIVERING)' 상태로 변경이 가능하다.
      - [ ] 주문의 타입이 배달(DELIVERY) 이어야 한다.
      - [ ] 주문의 상태가 서빙됨(SERVED) 이어야 한다.
    - [ ] 주문은 '배달완료(DELIVERD)' 상태로 변경이 가능하다.
      - [ ] 주문의 상태가 배달중(DELIVERING) 이어야 한다.
    - [ ] 주문은 '완료(COMPLETED)' 상태로 변경이 가능하다.
      - [ ] 주문 타입이 배달(DELIVERY) 인 경우
        - [ ] 주문 상태가 배달완료(DELIVERD) 인 경우에 변경이 가능하다.
      - [ ] 주문 타입이 포장(TAKEOUT) 인 경우
        - [ ] 주문의 상태가 서빙됨(SERVED) 인 경우에 변경이 가능하다.
      - [ ] 주문 타입이 매장식사(EAT_IN) 인 경우
        - [ ] 주문의 상태가 서빙됨(SERVED) 인 경우에 변경이 가능하다.
        - [ ] 해당 식사 테이블의 상태를 초기화 한다.
        
- 식사 테이블 (OrderTable) : 매장에서 먹고갈때 사용될 테이블
  - [ ] 식사 테이블은 생성될수 있다.
    - [ ] 이름(name)은 필수로 입력되어야 한다.
    - [ ] 테이블 손님수(numberOfGuests)를 0 으로 지정한다.
    - [ ] 테이블 사용여부(occupied)의 상태를 미사용(false)으로 지정한다.
  - [ ] 식사 테이블의 사용여부(occupied) 의 상태를 사용중(true) 로 변경할 수 있다.
  - [ ] 식사 테이블은 초기화 할수 있다.
    - [ ] 테이블의 주문의 상태가 완료(COMPLETED) 라면 초기화 할수 없다.
    - [ ] 테이블 손님수(numberOfGuests)를 0 으로 지정한다.
    - [ ] 테이블 사용여부(occupied)의 상태를 미사용(false)으로 지정한다.
  - [ ] 식사 테이블을 사용중인 손님의 수를 변경할 수 있다.
    - [ ] 변경되는 손님수는 0이상의 숫자이어야 한다.
    - [ ] 사용중인 테이블이 아니면 손님수를 변경할 수 없다.

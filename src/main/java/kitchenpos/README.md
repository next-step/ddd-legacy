## 요구 사항
> ``메뉴``와 ``상품``을 등록 가능하고, 
> 
> ``주문``이 가능한 키친 포스 시스템을 개발한다.


- ### 📌 메뉴 (menu)
  - ⭕️ 필수조건
    - [ ] 메뉴 명, 가격, 노출 여부, 메뉴 상품 리스트를 가진다.
    - [ ] 메뉴 그룹에 속한다.
  - ⭕️ 기능
    - [ ] 메뉴 생성
      - 생성할 매뉴의 가격은 무조건 0원 이상이어야 한다.
      - 생성할 메뉴는 메뉴 그룹에 속해있어야 한다.
      - 메뉴 상품이 무조건 존재해야 한다.
      - 메뉴 상품은 전체 상품 목록 내 존재해야 한다.
      - 메뉴 상품의 수량은 최소 1개 이상이어야 한다.
      - 메뉴의 가격이 전체 메뉴 상품의 가격보다 작거나 같아야 한다.
      - 메뉴 명은 무조건 존재해야하고, 비속어가 포함되면 안된다.
    - [ ] 메뉴 가격 변경
      - 변경할 메뉴의 가격은 무조건 존재해야하고, 0원 이상이어야 한다.
      - 변경할 메뉴의 가격이, 전체 메뉴 상품의 가격보다 작거나 같아야 한다.
    - [ ] 메뉴 판매 가능으로 변경
      - 판매 가능으로 변경할 할 메뉴는 기존 메뉴에 존재해야한다.
      - 판매 가능으로 변경할 메뉴의 가격이 전체 메뉴 상품의 가격보다 작거나 같아야 한다.
    - [ ] 메뉴 판매 불가능으로 변경
      - 판매 불가능으로 변경할 할 메뉴는 기존 메뉴에 존재해야한다.
    - [ ] 전체 메뉴 조회
- ### 📌 메뉴 그룹 (menu group)
  - ⭕️ 필수조건
  - [ ] 메뉴 그룹 명을 가진다.
  - ⭕️ 기능
    - [ ] 메뉴 그룹 생성
      - 메뉴 그룹 명이 존재해야 한다.
    - [ ] 전체 메뉴 그룹 조회

- ### 📌 주문 (order)
  - ⭕️ 필수조건
    - [ ] 주문 타입을 가진다.
      - 주문 타입 (order type) : 배달, 포장, 매장 식사
    - [ ] 주문 상태를 가진다.
      - 주문 상태 (order status) : 대기, 수락, 제공 완료, 배달 중, 배달 완료, 완료
    - [ ] 주문 일시를 가진다.
    - [ ] 주문 순서를 가진다.
      - 주문 항목 (order line)
        - 자동적으로 순서를 가진다.
        - 메뉴, 수량을 가져야 한다.
  - ⭕️ 기능
    - [ ] 주문 생성
      - 주문 타입 | _공통_
      - 주문 타입이 존재해야 한다.
      - 주문 항목에 존재해야 한다.
      - 주문 항목의 메뉴들은 기존 메뉴에 존재해야 한다.
      - 주문 항목의 메뉴는 판매 가능한 메뉴여야 한다.
      - 메뉴의 가격과 주문 항목의 가격은 동일해야한다.
      - 주문 항목의 수량은 1개 이상이어야 한다 (단, 주문 상태가 매장 식사인 경우는 제외).
      - 주문 타입 ㅣ _매장 식사_
        - 테이블이 미사용이어야 한다.
      - 주문 타입 ㅣ _배달_
        - 배달 주소가 무조건 존재해야 한다.
    - [ ] 주문 수락
      - 현재 주문 상태는 대기 상태여야한다.
      - 주문 타입 ㅣ _배달_
        - 주문 항목의 메뉴 가격을 모두 합산하여 배달 요청 후 주문 상태를 "수락"으로 변경한다.
    - [ ] 주문 제공
      - 현재 주문 상태가 수락이어야 한다.
      - 주문 제공 후, 주문 상태를 "제공 완료"으로 변경한다.
    - [ ] 배달 시작
      - 주문 타입 ㅣ _배달_
        - 현재 주문 타입이 "배달" 이외의 상태여야 한다.
        - 현재 주문 상태가 "제공 완료" 이외의 상태여야 한다.
        - 주문 상태를 "배달 중"으로 변경한다.
    - [ ] 배달 완료
      - 주문 타입 ㅣ _배달_
        - 현재 주문 상태가 "배달 중"이여야 한다.
        - 주문 상태를 "배달 완료"로 변경한다.
    - [ ] 주문 완료
      - 주문 타입 | _공통_
        - 주문 상태를 "완료"로 변경 한다.
      - 주문 타입 | _배달_
        - 주문 상태는 "배달 완료"여야 한다.
      - 주문 타입 | _포장_
        - 주문 상태는 "제공 완료"여야 한다.
      - 주문 타입 | _매장 식사_ 
        - 주문 상태는 "제공 완료"여야 한다.
        - 주문 테이블 상태를 "미사용", 인원 "0" 으로 변경 한다.
      
    - [ ] 전체 주문 조회

- ### 📌 주문 테이블 (order table)
  - ⭕️ 필수조건
    - [ ] 인원 수와 테이블 명, 고객 인원 수, 사용 여부를 가져야 한다.
  - ⭕️ 기능
    - [ ] 테이블 생성
      - 최초 테이블 생성 시 테이블 명이 존재 해야 한다.
    - [ ] 테이블 착석
      - 존재하는 테이블에 대해 착석이 가능하다.
      - 테이블 사용 여부를 "사용 중"으로 변경한다.
    - [ ] 테이블 정리
      - 존재하는 테이블에 대해 정리가 가능하다.
      - 테이블 사용 여부를 "미사용"으로 변경한다.
    - [ ] 테이블 인원 수 변경
      - 테이블에 착석하는 인원 수가 1명 이상이어야 한다.
      - 존재하는 테이블에 대해 인원 수 변경이 가능하다.
      - 테이블은 "사용 중"상태여야 인원 수 변경이 가능하다.
      - 테이블 인원 수를 변경 한다.
    - [ ] 전체 테이블 조회
    
- ### 📌 상품 (product)
  - ⭕️ 필수조건
    - [ ] 상품 명과 가격을 가져야 한다.
  - ⭕️ 기능
    - [ ] 상품 생성 가능
      - 가격은 무조건 존재 하여야 한다.
      - 가격은 0원 미만이면 안 된다.
      - 상품 명은 무조건 존재 하여야 한다.
      - 상품 명은 비속어가 포함되면 안된다.
    - [ ] 상품 가격 변경 가능
      - 가격 변경시 어떤 상품의 가격을 변경할지 지정해야 한다.
      - 변경할 상품은 기존에 존재하는 상품이어야 한다.
      - 변경 할 가격은 무조건 존재 하여야 한다.
      - 변경 할 가격은 0원 미만이면 안 된다.
      - 변경할 상품이 포함된 메뉴들 중, 메뉴의 총 가격이 상품의 가격 합 보다 크면 메뉴는 판매 불가능으로 변경한다.
    - [ ] 전체 상품 조회 가능

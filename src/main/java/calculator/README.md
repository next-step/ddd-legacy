# 문자열 덧셈 계산기


## 클라이언트 분석

* Actor : 구분자 문자열을 가지고 숫자의 합을 계산하는 사용자

## 클라이언트 요구사항 분석
* 계산기는 구분자와 숫자로 구성된 문자열을 입력받아 숫자의 합을 반환한다. 
* 숫자를 구별할 구분자를 지정할 수 있다. 
  * 구분자는 기본적으로 콜론(:)과 콤마(,)를 제공한다.
  * 구분자 지정은 문자열 앞부분의 `//`와 `\n` 사이에 위치하는 문자로 지정한다.
* 문자열 계산기에는 숫자 이외의 값 또는 음수가 전달될 수 없다.
  * 숫자 이외의 값 또는 음수가 전달되면 `RuntimeException`을 발생시킨다.

---

## 역할 설계
* Calculator : 계산기
  * 'StringAdditionalCalculator' : 문자열 덧셈 계산기 구현체
* Operation : 계산기 연산
  * Addition : 덧셈 연산 구현체
* ExpressionParser : 문자열을 계산식으로 변환
* Delimiters : 구분자
* DelimiterStrategy : 구분자 지정 전략
* Validator : 유효성 검사


## 고민점

* 입력값 유효성 검사를 어떻게 해야할까?
  * 공백, null 체크
  * 숫자 이외의 값 체크

### 메뉴 그룹

- 메뉴 그룹을 생성한다
    - 메뉴 그룹은 반드시 이름이 있어야 한다
    - 메뉴 그룹 생성 시 고유한 식별자가 부여된다

- 존재하는 메뉴 그룹 전체를 조회 한다

---

### 메뉴

- 메뉴를 생성한다
    - 메뉴의 이름은 반드시 존재해야 하며, 비속어를 포함할 수 없다
    - 메뉴의 가격은 반드시 존재해야 하며, 0 이상이어야 한다
    - 메뉴는 반드시 하나의 메뉴 그룹에 속해야 한다
    - 메뉴 상품들은 반드시 존재해야 한다
        - 메뉴 상품의 수량은 0보다 커야 한다
        - 등록되지 않은 상품은 메뉴 상품으로 추가할 수 없다
        - 메뉴의 가격은 메뉴 상품들의 총 가격 합계를 초과할 수 없다

- 메뉴의 가격을 수정한다
    - 메뉴는 반드시 존재하는 메뉴여야 한다
    - 메뉴의 가격은 반드시 0 이상이어야 한다
    - 메뉴의 가격은 메뉴에 포함된 상품들의 총 가격 합계를 초과할 수 없다

- 메뉴를 보임으로 수정한다
    - 메뉴는 반드시 존재하는 메뉴여야 한다

- 메뉴를 숨김으로 수정한다
    - 메뉴는 반드시 존재하는 메뉴여야 한다

- 존재하는 전체 메뉴를 조회한다

---

### 주문

- 주문을 생성한다
    - 주문 기본 정보 검증
        - 주문은 반드시 타입(배달/포장/방문)을 가져야 한다
        - 주문 생성 시점의 상태는 '대기 중'으로 설정된다
        - 주문 시각이 자동으로 기록된다

    - 주문 항목 검증
        - 주문은 반드시 하나 이상의 주문 항목을 포함해야 한다
        - 주문한 메뉴가 실제로 존재해야 한다
        - 주문한 메뉴는 현재 판매 중(displayed) 상태여야 한다
        - 주문 항목의 가격은 메뉴의 현재 가격과 일치해야 한다
        - 수량 제약
            - 방문 식사의 경우 수량 제한이 없다
            - 배달/포장의 경우 수량은 1 이상이어야 한다

    - 주문 타입에 따른 추가 검증
        - 배달 주문인 경우
            - 배달 주소는 반드시 입력되어야 한다
            - 배달 주소는 공백일 수 없다
        - 방문 식사인 경우
            - 주문 테이블이 반드시 지정되어야 한다
            - 지정된 테이블은 현재 사용 중(occupied) 상태여야 한다

- 주문을 수락한다
    - 주문은 반드시 존재하는 주문이어야 한다
    - 주문은 반드시 대기 상태여야 한다
    - 배달 주문인 경우
        - 주문 총액을 계산한다
        - 배달 기사를 요청한다
            - 주문 번호, 총액, 배달 주소가 필요하다
    - 주문 상태를 수락됨으로 변경한다

- 주문을 서빙 상태로 변환한다
    - 주문은 반드시 존재하는 주문이어야 한다
    - 주문은 반드시 수락 상태여야 한다

- 주문을 배달 시작으로 변환한다
    - 주문은 반드시 존재하는 주문이어야 한다
    - 주문의 타입은 반드시 배달이어야 한다
    - 주문은 반드시 서빙된 상태여야 한다
    - 주문 상태를 배달 중으로 변경한다

- 주문을 배달 완료로 변환한다
    - 주문은 반드시 존재하는 주문이어야 한다
    - 주문 상태는 반드시 배달 중 이어야 한다

- 주문을 완료 처리한다
    - 주문은 반드시 존재하는 주문이어야 한다

    - 주문 타입별 완료 조건
        - 배달 주문의 경우
            - 주문 상태가 반드시 배달완료여야 한다
        - 포장/방문 주문의 경우
            - 주문 상태가 반드시 서빙됨이어야 한다

    - 완료 처리 후 추가 동작
        - 방문 주문의 경우
            - 해당 테이블의 다른 주문이 모두 완료 상태라면
                - 테이블의 손님 수를 0으로 변경한다
                - 테이블을 비어있음으로 변경한다

- 존재하는 모든 주문을 조회한다

--- 

### 주문 테이블

- 테이블을 생성한다
    - 테이블의 이름은 반드시 존재해야 한다
    - 테이블 생성 시 고유한 식별자가 부여된다
    - 초기 손님 수는 0으로 설정된다
    - 초기 상태는 비어있음으로 설정된다

- 테이블에 착석한다
    - 테이블은 반드시 존재하는 테이블이어야 한다
    - 테이블 상태를 점유됨으로 변경한다

- 테이블을 치운다
    - 테이블은 반드시 존재하는 테이블이어야 한다
    - 테이블에 완료되지 않은 주문이 없어야 한다
    - 손님 수를 0으로 변경한다
    - 테이블 상태를 비어있음으로 변경한다

- 손님의 수를 변경한다
    - 테이블은 반드시 존재하는 테이블이어야 한다
    - 테이블은 반드시 점유된 상태여야 한다
    - 변경하려는 손님 수는 0 이상이어야 한다

- 존재하는 모든 테이블을 조회한다

---

### 상품

- 상품을 생성한다
    - 상품의 가격은 존재해야 하고 0보다 커야한다
    - 상품의 이름은 존재해야 하며 비속어를 포함할 수 없다

- 상품의 가격을 변경한다
    - 상품은 반드시 존재하는 상품이어야 한다
    - 상품의 가격은 반드시 0보다 커야 한다
    - 가격 변경 시 연관된 메뉴 처리
        - 해당 상품을 사용하는 모든 메뉴를 조회한다
        - 각 메뉴의 전체 구성 가격을 다시 계산한다
        - 메뉴의 판매 가격이 구성 가격보다 높은 경우 해당 메뉴를 숨김 처리한다

- 존재하는 모든 상품을 조회한다

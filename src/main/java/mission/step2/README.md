### 메뉴 그룹

- 메뉴 그룹을 생성한다
    - 메뉴 그룹은 반드시 이름이 있어야 한다
    - 메뉴 그룹 생성 시 고유한 식별자가 부여된다

- 존재하는 메뉴 그룹 전체를 조회 한다

### 메뉴

- 메뉴를 생성한다
    - 메뉴의 이름은 반드시 존재해야 하며, 비속어를 포함할 수 없다
    - 메뉴의 가격은 반드시 존재해야 하며, 0 이상이어야 한다
    - 메뉴는 반드시 하나의 메뉴 그룹에 속해야 한다
    - 메뉴 상품들은 반드시 존재해야 한다
        - 메뉴 상품의 수량은 0보다 커야 한다
        - 등록되지 않은 상품은 메뉴 상품으로 추가할 수 없다
        - 메뉴의 가격은 메뉴 상품들의 총 가격 합계를 초과할 수 없다

- 메뉴의 가격을 수정한다
    - 메뉴는 반드시 존재하는 메뉴여야 한다
    - 메뉴의 가격은 반드시 0 이상이어야 한다
    - 메뉴의 가격은 메뉴에 포함된 상품들의 총 가격 합계를 초과할 수 없다

- 메뉴를 보임으로 수정한다
    - 메뉴는 반드시 존재하는 메뉴여야 한다

- 메뉴를 숨김으로 수정한다
    - 메뉴는 반드시 존재하는 메뉴여야 한다

- 존재하는 전체 메뉴를 조회한다

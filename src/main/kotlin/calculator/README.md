## 요구 사항

* 기본 구분자(쉼표(,), 콜론(:))을 구분자로 가지는 문자열의 경우 구분자를 기준으로 분리한 각 숫자의 합을 반환한다.
* 기본 구분자 외에 커스텀 구분자는 다음 규칙에 따라 지정할 수 있다.
    * 문자열 앞 부분의 `//`와 `\n` 사이에 위치한 문자를 구분자로 사용한다.
    * 예시: `//;\n1;2;3` -> `6`
* 빈 문자열 또는 `null`을 입력할 경우 0을 반환한다.
* 숫자 하나를 입력할 경우 해당 숫자를 반환한다.
* 숫자 이외의 값 또는 음수를 전달할 경우 RuntimeException을 발생시킨다.

## 구현할 클래스

* Calculator (계산기)
    * ParsingService: 주어진 문자열을 파싱
    * SummationService: 주어진 숫자의 합을 계산
* InputString: 주어진 문자열
* Delimiter: 구분자
* NonNegativeNumber: 음이 아닌 정수

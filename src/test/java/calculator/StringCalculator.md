# 문자열 계산기 요구사항

## 기본 요구사항
1. 빈 문자열 또는 null 입력 처리
    - 입력이 null이거나 빈 문자열인 경우 0을 반환해야 함

2. 단일 숫자 처리
    - 하나의 숫자만 입력된 경우 해당 숫자를 반환해야 함
    - 예: "1" → 1

3. 쉼표(,) 구분자 처리
    - 쉼표로 구분된 두 숫자의 합을 반환해야 함
    - 예: "1,2" → 3

## 확장 요구사항
4. 다중 구분자 지원
    - 쉼표(,) 외에 콜론(:)도 구분자로 사용 가능
    - 예: "1,2:3" → 6

5. 커스텀 구분자 지원
    - "//"와 "\n" 사이에 위치한 문자를 커스텀 구분자로 사용
    - 커스텀 구분자는 한 문자만 가능
    - 예: "//;\n1;2;3" → 6
    - 예: "//.\n1.2.3" → 6

## 예외 처리
6. 음수 처리
    - 음수가 입력될 경우 RuntimeException 발생
    - 예: "-1" → RuntimeException

## 제약 조건
- 모든 입력 숫자는 정수로 가정
- 구분자는 입력 문자열 시작 부분에 위치
- 커스텀 구분자는 한 문자만 허용
